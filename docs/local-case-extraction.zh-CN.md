# v5.1 可信内网案件提取适配器

本说明对应源码工作包，不代表已经接通业务模型或发布 Stable。

## 配置与使用

默认 `CASE_SEMANTIC_MODEL_ID` 为空：案件继续使用现有本地规则，不调用模型。

部署管理员在原有模型配置页登记内网 `openai-compatible` 或 `openai` 协议服务，填写模型名、服务基址和密钥。服务基址是内网地址，例如管理员自己的 `/v1` 基址，而不是外部供应商默认地址；主机须在 `TRUSTED_LOCAL_MODEL_HOSTS` 中明确列入。兼容协议不等于授权外发。当前适配器不支持 Anthropic 或 Azure 专用认证协议。

将后台 Worker 的 `CASE_SEMANTIC_MODEL_ID` 指向该登记编号，并保持 API 与 Worker 使用一致的模型选择及可信主机配置。本文不提供真实地址或密钥，也不替部署人员自动修改环境。

- 案件正常保存只写原有事件；后台读取待分析文本，释放数据库事务后才调用模型。
- 仅向可信内网服务发送语义字段，服务端不继承环境代理、不跟随重定向、不自动重试、不向外部模型降级。
- 请求最多 96 KB，返回最多 64 KB，最多 30 个选取片段。单次网络读写超时 20 秒，响应读取同时检查 45 秒预算；慢连接可能在下一次读写超时才结束，因此不是严格的 45 秒全程承诺。
- 模型输出只允许限定类别、肯否类型和逐字引用。工具调用、非法结构、截断响应均不采用。引用位置按 Unicode 字符校验；无效引用保留未知，不恢复成无出处的自由文本。
- 选取片段不代表穷尽原文。引用真实只证明出处存在，不证明模型分类、肯否判断或原文陈述已核实；原规则画像、人工判断和正式案件相互分开。
- 模型提取候选显示在现有画像中，并随同一冻结成果导出。当前不自动用于设施候选评分或正式案件关系。

## 版本、更新与失败恢复

画像绑定原文摘要及提取配置版本。配置版本包含规则、适配器、登记编号、模型名、服务基址、登记更新时间、`config.revision` 和可信主机范围的摘要；不在成果中暴露地址或密钥。

等待模型期间案件可继续编辑。模型返回后重新读取案件、事件和配置；发现来源或配置变化即弃用旧输出，并为最新内容续建。已提交画像不被原地覆盖，读取工作界面和最新成果时会标记过期版本。

配置切换后，新保存案件自动使用新版本。历史案件通过已有管理员画像回填入口分批处理，不因读取页面而生成任务；当前不自动向全部历史案件广播配置变化。

模型暂不可用时，后台仍完成规则画像，模型部分显示“暂不可用”。相同数据和配置不反复调用。需要重试这类已完成的降级画像时，管理员更新该模型的 `config.revision`（如内网模型版本或运维重建批次），再执行分批回填；不会修改旧成果或正式事实。这是当前兼容重建路径，尚无独立的模型失败重试按钮。

取消模型选择并让 API/Worker 配置一致即可停止后续模型调用；历史成果按版本保留。没有新增本工作包数据库迁移；此前统一检索所需 PostgreSQL/pgvector 迁移仍须按其部署说明执行。

## 已验证与未验证

已用合成原文验证结构、引用、否定保护、拒绝外部主机/重定向、故障降级、源内容和模型变更、HTTP 回环协议、页面及导出。

一次性真实 PostgreSQL 中，模型响应等待时第二个连接可在 1 秒锁超时限制内修改案件；旧输入结果被弃用，最新事件能够生成画像；数据库备份可恢复。本测试使用合成模型响应，不是实际模型质量验收。

尚未接入用户部署环境的真实模型，未验证深层抽取效果、现场延迟或目标服务器表现。不得把当前聊天模型、模拟响应或这些契约测试当成真实模型验收。
