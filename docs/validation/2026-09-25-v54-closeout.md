日期：2026-09-25。范围为 5.x 路线图的“重点设施与区域综合研判”。上一恢复点 `v5.3.0-stable`（`9a144e1`，与开发基线 `d31bd7b` 源码树一致）。本文件记录源码与隔离组件验收，不代表目标服务器投产、真实模型或正式业务效果。

## 要求与实现

| 要求 | 实现及证据 |
|---|---|
| 同一设施从多入口打开同一档案 | `FacilityDossierDrawer`、`facility_analysis.py`；案件候选、生产图层、辖区及大屏只传稳定 ID，共用当前授权只读服务；深链接及浏览器通过 |
| 明确记录、邻近、候选分开 | `facility_dossier_content.py` 使用原始事件双外键、直线邻近和已保存候选三个独立分区，采纳反馈不升级为明确事实；保留事件复核状态 |
| 生产来源、历史名称及版本 | 新写入/修改记录真实设施版本；现有无历史设施仅记“本次观察基线”，不伪造过去；同名不同编号不误合并，原有疑似误合并不自动拆分 |
| 道路、技防、报告及资料缺口 | 只复用可信入口、已有通行条件和已冻结道路成果；资料受限不返回内容或数量，技防资料缺失不等于无覆盖，历史成果按当前权限核验全部来源 |
| 全授权历史条件对照 | `facility_condition_comparison.py` 批量核验全部匹配画像的原案件哈希、原文位置和表述；设施分页但历史不截最近 N 起，有限案例仅作例示；过期生产属性不作当前肯定匹配，无风险分 |
| 共享区域地图与时间线 | 区域、时空、案件地图、辖区和大屏共享范围及实体选择；起始包含/截止不含；月度、星期/小时按 `Asia/Shanghai` 分桶，案件和事件不混计 |
| 不用样本冒充总体 | 设施服务端分页；案件/事件地图各最多 500 条并披露截断，完整统计包括无坐标案件；未套用案件专有过滤条件明确说明 |
| 资料变化可解释 | 后台仅持久化可重建目录摘要，每次读取重新按当前权限组成跨案证据；来源摘要及各分区内容指纹解释变化；保守巡检不冒充精准依赖增量 |
| 不增加日常必需操作 | GET 不写数据库、不触发模型/路由；摘要后台维护，队列不可用可继续读取并显示待更新；大屏普通入口默认滚动七天，不要求额外选范围 |

## 冻结本机读取性能

固定合成规模：102 个授权设施、201 个授权案件、200 个当前画像、1 个受限设施。每项五次请求；样本很小，表中为观测值，不作生产容量保证。

| 读取项 | 中位耗时 | 观测 P95 |
|---|---:|---:|
| 区域第 1 页 / 20 个设施 | 54.174 ms | 58.072 ms |
| 单设施综合档案 | 54.638 ms | 144.377 ms |

本版未增加案件保存同步计算或修改保存主路径，复用 v5.3 冻结保存性能证据；不声称已重新测量目标服务器保存 P95。

## 实际浏览器

`scripts/seed-v54-ui-fixture.py` 只在空临时目录建立合成 SQLite；真实登录分析员，2 个同名不同编号设施、3 个案件（1 个无坐标）、2 个事件（1 个独立）。模型和 Agent Lab 关闭。单瓦片合成底图明确标注“非真实地图”，只核验集成，不充当两市地图覆盖验收。

- 区域全量统计 3 起案件包含无坐标记录；2 个设施保持独立，事件与独立事件分别显示。
- 区域点击及辖区深链接打开设施 1 的同一综合档案；明确记录、空间邻近和候选分开，摘要版本和来源可查看；从档案直接打开关联案件，关闭设施浮层且保留共享条件。
- 大屏无参数入口自动使用最近七天；多轮轮询观察截止时刻前移，登记井点打开稳定编号对应的档案。
- 案件地图保留设施 ID 和精确共享窗口；失效/不可访问设施显示失败，不替换成其它设施。
- 本地快照和截图位于 `output/playwright/v54-*`，不把运行产物或数据副本发布到 GitHub。
- 开发 StrictMode 取消重复请求仍由已有日志显示为 NetworkError，对应有效请求为 200；辖区旧表单有 Modal 废弃属性/useForm 提示，未把本次验收称为零控制台警告。受控重启期间的失败不作为正常业务成功记录。
