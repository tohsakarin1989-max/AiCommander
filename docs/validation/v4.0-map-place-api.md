# v4.0 离线地名查询接口工作包

日期：2026-09-10。阶段：开发验证，不是 Stable 发布。

## 已实现

- `GET /api/maps/{snapshot_ref}/places?q=大庆&limit=20`，支持已发布版本 ID、版本名或 `current`，可按 `operational_area_id` 限定。
- 先用现有辖区授权解析快照，再从该快照的公共包获取唯一 `gazetteer` 成果物。不允许传入文件路径、外部 URL 或独立公共包编号。
- 每次重新检查权限，不缓存授权结果；成功响应使用 `private, no-store`。
- 输入限制为 2—120 字符、最多 50 项。字面子串匹配，不把 SQL 或通配符当成表达式。
- 索引最大 64 MiB，检查实际大小和 SHA-256；SQLite 查询使用同一份已校验字节，避免校验后替换文件导致读取不同内容。
- 返回快照 ID、版本、索引摘要、公共来源摘要、搜索算法以及“公共地名参考点”的适用边界。构建路径和诊断元数据不外显。
- 无匹配为正常空列表；旧版本没有索引为 409；索引缺失、损坏、重复绑定或校验失败为 503；未授权版本为 404；未登录为 401。
- 地名参考点不自动写入案件，不代表核验过的道路入口、精确地址或机动车可达终点。

## 验证

- 14 项 API 测试通过，覆盖匹配、空结果、非法输入、旧地图、文件异常、登录、辖区隔离、权限撤销、历史/当前版本分离及额外内部列不外显。
- 与索引模块合计 26 项定向测试通过；增补字段白名单前的 25 项覆盖测量为服务 94%、索引模块 92%。
- 后端全量 582 passed、1 skipped，23.24 秒，包含链条分析回归。跳过的可选真实 PostGIS 环境测试不计作已验证。
- 前端生产构建通过；仍存在原有大分块提示，未进行本轮浏览器验收。
- Python 审查无高优先级阻断；发现扩展列可能透传后，先复现失败测试，再改用显式字段白名单，26 项定向复验通过。静态分析工具仍未配置，未记作通过。

## 尚未交付

当前正式公共地图导入仍是 schema 1，仅支持旧栅格包。本轮没有放宽该校验器，也没有把实际地名候选手动注册进生产数据库。接口由隔离测试注册的成果物验证；正式包集导入应在 schema 2 中绑定并核验地名资产后开放。

后续继续：schema 2 包集与本地资源契约 → MapLibre 和地名搜索页面 → 断公网冷启动与发布回滚 → v4.0 其余验收。版本号保持 `3.6.0-stable`，不创建 GitHub Release。
