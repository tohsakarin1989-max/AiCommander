## 全地图文字检查发现的剩余问题

对固定摘要的真实MBTiles全部记录扫描；按当前页面三类标签图层 `place / poi / transportation_name`，
使用 `coalesce(name:zh, name:latin, name)` 优先级收集文字，不只检查地名索引。
重复瓦片缓存只跳过相同内容，不抽样；扫描前后文件摘要一致。

- 处理跨缩放级别标签394,909个（去除部分重复瓦片后），不是独立现实地名数。
- 非空白字符共2,608种。
- 当前固定字形中缺少Š（U+0160）、部分蒙古文字符/格式选择符，以及🏡、🏥（非BMP）。
- 格式选择符不能简单按“独立可绘制字形”处理；需要正确区分文字成形控制与可见字符。
- 现有协议只声明BMP字形分段，不能声称两个非BMP符号已能离线绘制。

因此 `font_coverage_verified` 仍为false。需补字体与成形兼容策略，或对显示标签采用明确且不改写原始数据的兼容处理，并保留原文可查；不能把缺字忽略后宣称全部覆盖。
