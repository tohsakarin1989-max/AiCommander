# v4.0 离线矢量地图基础样式

2026-09-10，基础契约验证，尚未切换正式地图页面。

## 本轮实现

- 固定安装 `maplibre-gl@6.9.0`；保留 Leaflet 及原有地图路径。
- 新增 `createOfflineVectorStyle`，只接受 UUID 快照 ID，不接受 `current` 或外部 URL。瓦片和字形引用绑定同一固定版本。
- 原生瓦片层级 6—16，显示上限 19；初始化参数关闭系统 CJK 字形替代，字体栈与本地生成器一致。
- 提供背景、植被、土地使用、公园、水体、水道、建筑、行政边界、道路、铁路、道路名、POI 名、地名共 14 层样式。
- 公共底图不包含案件与内部生产要素；相关业务图层继续独立处理。
- 道路外观不代表已确认可通行，元数据记录适用边界。当前样式未请求 sprite；后续图标资源仍需随实际符号层一起完成本地化，不以“不请求图标”认定全部图标要求完成。
