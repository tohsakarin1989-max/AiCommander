# v4.0 第二工作包：导入可靠性与地图源数据

日期：2026-09-10。当前仍为开发工作包，不是 v4.0 或 v4.5 Stable 发布声明。

## 已实现

- CSV/Excel 支持常见中文表头、显式工作表名称、表头行和白名单字段映射；前端提供工作表/表头行设置。未知列明确提示，不允许上传内容选择辖区或写入安全字段。
- 重复表头、同一目标字段的映射冲突、无表头数据、坏 ZIP/XML、超限文件在写入前拒绝。保留实际物理行号，包括空白行和 CSV 多行单元格。
- 数值/坐标/是否类字段严格验证，预览和正式导入使用同一份解析结果；报告单位与保卫队冲突不静默舍弃。
- 新增 `case_import_batches`：唯一输入身份、授权辖区、发起人、解析版本和回执。案件、质量信息、Outbox 与回执在同一事务提交；单行失败使用保存点隔离。
- 相同原始文件、辖区、工作表和表头行重传恢复原回执，`created=0`、`replayed=true`、`original_created` 标明原创建数。别名/解析软件升级不自动重建案件；变更映射也不允许对原文件隐式重复建案。
- 原派生索引/链条处理放在业务提交后，失败不把已完成导入报告成失败；案件画像 Outbox 保持持久化。
- 导入完成保留页面回执、完整错误清单和批次编号，不再输出案情到浏览器控制台；成功后清空已选文件，避免重复点击。
