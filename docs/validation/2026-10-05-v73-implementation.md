## 接口兼容

- 设施目录保持原数组，增加可选 `search_match`，区分现名、编号、地址、历史名称和来源别名。可见性与来源过滤发生在计数/分页前。
- 设施档案保留 `valid_at`、`known_at` 点查询，新增请求 `valid_from`/`valid_to` 与 `knowledge_mode`。明确口径的非法、混合或不完整参数应拒绝，不默认切回当前。
- 区间响应新增 `query_interval`，旧响应 `valid_from`/`valid_to` 仍指所选单一版本的有效期，不能偷换含义。分段说明完整/部分/未知、冲突、迟到补充与来源引用。
- 从冻结候选展开设施时，携带原成果完整区间和已记录获知截止；没有历史时间时明确只看当前资料，不宣称还原案发时条件。
- 跨页 URL 中的对象/时间/来源只是阅读上下文，不是权限或自动改变原成果的指令；返回位置仅允许已知站内页面，不复制密钥、任意网址或嵌套返回地址。
