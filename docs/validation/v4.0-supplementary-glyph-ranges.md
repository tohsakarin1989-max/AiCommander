# 补充平面字形接口及包集兼容

2026-09-10；v4.0开发工作包，尚未完成完整字体接入或发布。

## 已实现

统一字形范围解析，解码器、授权接口、库存键和样式/包集验收使用同一规则：

- 256码位一段，范围写法规范，无前导零或路径字符；终点最多U+10FFFF。
- 保留现有256段BMP基础要求，只按需追加补充平面，资产总量/分片/字节限制不变。
- 已注册的`127744-127999`分段可通过原授权接口读取；未登记分段404、越界422、授权撤销404。
- 仍验证文件大小、摘要、嵌入字体组和范围；不将合法范围当作已具备字形。
- 不改变旧字体标识，也没有修改当前地图资产。

## 测试

- 新增U+10000、U+1F3E5及Unicode末段的实际protobuf结构解码测试。
- 补充平面接口访问、未登记、撤销权限、库存文件损坏和不规范范围测试。
- 联合渲染验收实际读取第257段protobuf；摘要正确但嵌入范围错误仍拒绝。

## 实际字体生成探测

使用已固定的MapLibre Font Maker WASM及三份已验证字体字节：CJK、Mongolian、Noto Emoji。
在内存中调用其原生fontstack添加与生成接口，未修改工具，不写入现用字体文件。

返回真实字体组标识：

```text
Noto Sans CJK SC Regular,Noto Sans Mongolian Regular,Noto Emoji Regular
```

新的组合字体名称与旧单字体不同，现有严格字体组校验仍会拒绝冒用旧名称的内容。
