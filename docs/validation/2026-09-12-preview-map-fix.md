## 重启后的可复现初始化

预览脚本新增显式 `AIC_UI_MAP_BUNDLE`：在进入临时目录和清理环境变量前解析文件路径，使用同一正式服务完成导入、一区快照构建和发布。初始化失败会阻止启动并报错。合规包、无包、损坏包和区域范围不符四个隔离分支通过，验证时未实际启动网络服务。

在仓库根目录重启完整后端时使用：

```bash
AIC_UI_FIXTURE=1 \
AIC_UI_MAP_BUNDLE="$PWD/backups/map-foundation/daqing-qiqihar/20260907/daqing-qiqihar-public-basemap-20260907-z6-14-rectangular.zip" \
backend/venv/bin/python scripts/serve-ui-verification.py
```

前端仍使用 13048，代理到 18068。不传地图包参数保留缺图负例用途，不能将这种启动方式称作地图已就绪的完整预览。没有边界或业务点的合成测试二区保持原状，不为通过验收伪造其地域范围。
