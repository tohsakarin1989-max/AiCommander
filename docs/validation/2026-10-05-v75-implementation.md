## 固定规模成本诊断

`test_facility_scale_v75.py` 仅执行一次固定诊断：Python 3.13.4 / SQLite 3.49.1、独立文件库、授权内 1000 个设施、200 起案件、2216 条依赖元数据。单轮指纹 43.874 毫秒（15 SQL/0 写），100 条扫描片 521.957 毫秒（552 SQL/6 写），状态读取 64.734 毫秒（37 SQL/0 写）。扫描按上限进入 pending，尚未执行矩阵。

这是保守授权范围重核成本，不是精准空间增量；每个成功块仍核对整个授权依赖，规模增大有成本。200 案未建语义索引，不含模型/真实矩阵，也不是并发负载或目标服务器容量证明。容量未实测在界面保持未知，不能由这些数值承诺员工人数。

## 边界

- 不使用聊天模型替代真实配置模型；未启用的语义能力继续显示规则回退。
- 不凭相似环节生成案件事实链，反向条件不是肯定支持。关键缺口不虚构补充收益，也不新增必填项。
- 管理员重试仅重新安排已失败的画像、索引和道路派生任务，不重放正式写入或审批，不复活取消任务。审计与排队同事务保存，重复请求使用原标识。
- 复用向量只保存必要哈希和向量；来源身份与授权由原记录核验，不能从缓存获得访问权。
- 继续保留 v7.1 编辑保存 P95 的失败证据；2026-10-08 用户接受本次 +8.20%（+2.058ms）单版例外，不降低测量阈值，不自动扩展到后续版本。
