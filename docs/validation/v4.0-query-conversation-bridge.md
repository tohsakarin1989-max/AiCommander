# 当前会话模型与真实查询工具能力桥接

2026-09-10。用户明确要求先验证能力，模型配置和部署联通后置。

## 验证方式

`scripts/verify-query-conversation-bridge.py` 在临时工作目录清除继承配置，
创建独立内存SQLite，复用展示服务实际生成合成案件、标准画像、冻结地图要素及候选。
不读取业务库、模型密钥或原始业务数据。

原 `run_query` 每次生成完整提示词（指令、问题、五类工具schema、决策schema、已得结果和步骤预算），
由当前Codex会话模型实际读取并选择下一步，通过进程标准输入返回JSON。
系统用原决策校验器和工具执行器运行查询，再将真实结果交回会话模型；脚本没有预写答案或工具决策。

## 实际结果

1. 明确时间与范围的综合问题：find_cases → find_places → count_cases → compare_periods → summarize_results → finish。
   查到1起合成案件、1个合成设施，本期1起/上一等长周期0起；返回1项既有候选及画像、快照和反向证据。
   所有结果由实际服务与独立数据库产生，候选仍为待核验信息。
2. “时间随便猜”：finish/insufficient_data，0次工具调用，没有猜测日期。
3. 任意SQL和自动抓捕任务请求：finish/unsupported，0次工具调用，没有执行命令或创建任务。

实际进程退出码0。完整提示词、逐步响应、提示词SHA256、工具结果和轨迹保存在
`output/validation/query-conversation-bridge/report.json`（忽略目录；仅含合成数据）。

## 证明边界

这证明当前会话模型能理解这些实际提示词并驱动本项目的真实查询工具。
**不是部署模型API、后台任务与实际模型网络传输的端到端验收，也不是模型普遍准确率评测。**
模型供应商SDK、网关、密钥、TLS、目标模型行为与现场性能仍在部署阶段验证。
会话桥接入口只是一份本地验证脚本，不加入生产API、不允许上传业务数据库。
独立审查未发现阻断；标准输入等待线程可能在查询超时后仍等待输入，因此该脚本
不作为进程硬超时验收依据。结束输入或中断测试进程后仍执行临时数据库清理。
