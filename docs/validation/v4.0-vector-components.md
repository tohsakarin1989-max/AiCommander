# v4.0 共用矢量地图组件接入

日期：2026-09-10。发布基线仍为 v3.6.0-stable，系列目标继续为 v4.5.0-stable。

## 实现

- 案件 LeafletMap、MapPicker、SpaceTimeMap 和 JurisdictionAssetMap 统一调用底图加载层。
- schema 1 继续使用已存在的栅格加载器；schema 2 使用固定 MapLibre 6.9.0 和官方适配器 0.1.4。原有案件点、热力和生产覆盖物仍由 Leaflet 管理。
- schema 2 必须声明固定快照 UUID、版本相符的本地样式/瓦片地址、原生 6—16 与展示 19；非法契约报错，不误转栅格，也不切到 current。
- 地图请求只允许同源固定快照的样式、瓦片、字体及图标，禁止外部 URL、其他 API、额外查询参数及混用辖区。
- Worker 通过 Vite `?worker&url` 打成自包含本地文件。中文使用已制备的 SDF 字形，不依赖客户端安装字体或 CDN。
- 未配置、载入中、失败分别提示；选点只有底图载入成功后开放。失败允许显式重试已解析的同一快照；重试不重复定位或重新解析 current。
- 构造失败立即移除半初始化图层；异步旧请求不能挂到已销毁页面。四组件关闭 CSS 缩放动画，避免 Leaflet 延迟 zoom 回调访问已移除地图。

适配器保留现有 Leaflet 交互，但不提供旋转和俯仰；后续仍需实测目标机器性能。
技术依据：[官方适配器](https://github.com/maplibre/maplibre-gl-leaflet)、[MapLibre Vite Worker 配置](https://maplibre.org/maplibre-gl-js/docs/#installation)。

## 明确限制

本次包含**开发构建及独立生产构建夹具的真实组件渲染验证**，地图 API 清单与资产响应由隔离脚本提供。
不是正式 schema 2 包集登记、发布或后端权限端到端验证；没有修改 current 或生产数据。
测试范围外缺失瓦片由夹具返回空 PBF，不代表生产允许隐瞒资源损坏。
实际生产接口与完整应用的冷启动、原生高层级细节、实际地域覆盖、路网引用闭合及共用地名搜索仍需继续验收。
不将构建成功或截图正常记作 v4.0 Stable，更不记作 v4.5 系列完成。
