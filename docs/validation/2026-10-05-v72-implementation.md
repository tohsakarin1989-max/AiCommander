## 交付范围与边界

- 复用来源、模板、声明、设施身份和地图包服务；补完整生产字段、结构漂移、逐行旧新差异、最近批次与异常续做。
- 坐标、含水率/口径、产量/单位/周期采用字段组，不跨来源拼凑；身份绑定与采用字段分开。同值来料保留接收记录但不重复增加业务设施版本。
- 台账原件使用现有 `EvidenceObject` 二进制容器，随导入事务保存，不开放文件路径、外部 URL 或主动执行。整份台账只允许地图管理员下载；普通设施档案展示自身来源行列。旧批次没有原件或冻结列映射时明确缺失，不回填猜测。
- 问题标注复用 `JurisdictionFeedback`，绑定设施及当时所见来源；不修改正式设施、不形成执行任务，也不计入旧部署采纳率。沿用当前账号及辖区写入权限，不放宽只读账号。
- 地点/计量明细按稳定 ID 更新，原有车辆、人员等明细独有语义保留。来源修订身份摘要与内容复用摘要分开；本版尚不复用模型结果，新来源修订仍正常排入既有管线，实际模型复用留至 v7.5。
- SQLite 的 10 张明细/来源对象表防 ID 再用选项必须通过实际迁移；只能保证迁移后不复用，不能替历史缺失身份补造对应关系。PostgreSQL 保留原序列机制。
