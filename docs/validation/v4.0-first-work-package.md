## 已实现

- `GET /api/cases/page`：服务端分页、完整授权库关键词搜索、多选分类和分类计数；旧列表接口保留。
- `GET /api/cases/dashboard-summary`：同辖区、同截止时刻、相邻同长度窗口；案发时间统计案件，完成时间统计双域成果。
- 地图最多展示500个案件点、500个登记井点，限额与缺失坐标说明显式展示，总数不由点位推算。
- 四指标、主地图、趋势与最多三类数量上升事实；没有上升不生成关注项，不把变化称为风险或因果关系。
- 按ID独立打开详情，更新会使详情和列表一起失效；删除移除详情链接及缓存。
- 登录、注销、失效和会话刷新清空查询缓存，晚到请求不能重新填入上一账号数据；详情拒绝访问不展示旧缓存。
- 大屏网络/5xx故障保留同范围旧图并标记过期，认证或权限拒绝移除数据；自动刷新保留用户视角，样本外证据有独立定位高亮。
- 移除固定“AI推理中”状态，改为实际模型配置状态，不声称模型正在执行。

## 时间与升级兼容

- 新增/更新案件的案发和报案时间先统一为UTC；响应明确带UTC时区。带偏移的ISO导入时间可正确解析。
- 无时区旧参数继续按UTC解释；下一工作包为Excel模板增加明确时间配置，不能猜测历史Excel的时区。
- SQLite历史记录可能已丢失原始偏移，无法仅凭数据库恢复。未批量平移或改写历史案件；真实数据需按原始来源核验。
- 后台画像哈希使用统一UTC-naive表示，避免入库前后仅时区表示不同就重复排队或跳过任务；旧SQLite格式保持兼容。
- 旧PostgreSQL带时区哈希可能发生一次表示变化，既有任务会按原流程失效后重新入队生成派生画像；不改写原始案件事实。
- 本轮未新增表结构或迁移，未改模型密钥、部署配置或正式数据库，未推送GitHub、未打新版本标签。
