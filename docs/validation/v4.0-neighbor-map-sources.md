## 可重复覆盖检查

工具 `scripts/verify-public-source-coverage.py` 使用多边形差集而不是包围框判断，
保存目标和各提供方范围文件摘要，报告不允许覆盖旧文件。
按照 [Osmosis POLY 格式](https://wiki.openstreetmap.org/wiki/Polygon) 顺序执行合并及排除，
修复重叠外环把排除区域重新填满的误判。当前严格输入契约要求显式闭合环。

有效报告为 `coverage-heilongjiang-v2.json`（不覆盖）和
`coverage-three-regions-v2.json`（覆盖），算法 `provider-polygon-ordered-v2`。
旧 v1 报告保留作诊断，不作验收证据。
