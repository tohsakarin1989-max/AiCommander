# v4.0 智能查询页面验证

日期：2026-09-10。开发基线仍为 v3.6.0-stable，本文不是 Stable 发布声明。

## 已接通的用户流程

现有“智能助手”切换到 `/api/intelligent-queries` 任务接口，不再调用旧的固定案件聊天入口。
用户输入问题后可查看排队、运行、取消、完成和降级状态；地址中的任务编号用于刷新恢复。
浏览器不额外持久化问题或成果。结果显示统计、列表、来源、查询条件、数据缺口与工具轨迹，
明确为历史查询结果，不自动成为案件结论。

未启用、无权限、模型不可用与零匹配分别呈现。账号或范围撤销后，读取失败即隐藏旧问题及结果。
取消接口允许权限撤销后取消任务，因此取消成功仅重新读取，不使用取消响应恢复旧缓存。

- `npm run test -- src/pages/Assistant/queryPresentation.test.ts`：3 项通过，退出 0。
- `npm run build`：类型检查与构建通过，退出 0；现有大文件分块警告仍存在。
- `scripts/verify-intelligent-query-ui.cjs`：本地 Chrome 8 个流程检查通过，退出 0。
  覆盖提交、刷新恢复、取消、零结果、1366/768/390 宽度布局、权限撤销、
  权限撤销后的延迟取消响应及功能关闭。测试期间公网请求为 0，页面异常为 0。
- 延迟取消回归：保持取消请求在途，读取返回 403；取消响应返回后继续暂停重新读取，
  断言旧问题和结果没有重新显示。独立只读复核确认原高优先级问题关闭。
