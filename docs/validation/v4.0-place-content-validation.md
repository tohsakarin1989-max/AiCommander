# 地名索引与可绘制字形联合验收

2026-09-10；v4.0 工作包，非 Stable 发布声明。

## 本轮交付

地图包后台验收现在同时检查地名索引：仅查询经过摘要核对的精确字节，在独立内存 SQLite 中核验表结构、源数据摘要、区域摘要、地点属性、坐标范围、名称与别名引用。重新生成预期的 2/3 字符搜索片段，与包内索引双向比较，拒绝遗漏、伪造、重复或孤立关联。

来源摘要必须匹配包中唯一 road_source 资产；区域摘要必须匹配包内某一 boundaries 资产。匹配摘要证明版本关联，不证明来源真实完整或边界几何正确，这些仍是后续门禁。

主地名的非空白、非格式字符必须在随包字体中具有非零尺寸，且 SDF 位图含有大于当前 MapLibre 内边缘阈值 0.75 的墨迹采样（字节值至少 192）。仅有非零字节仍可能完全透明，不计作覆盖。保留空格等字符的合法空位图，但仅存在字形编号不计作主地名可显示覆盖。该检查不识别位图形状是否语义正确，也不宣称任意别名或所有矢量标签均覆盖。

同时修复主地名空格填充绕过实际长度限制，以及异常巨大整数范围产生非预期 OverflowError 的问题。输入字节最多 64 MiB；校验有时间、地点数、名称数及搜索片段数量限制。不会修改源地名库或业务数据库。
