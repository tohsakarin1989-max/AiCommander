# 离线地图组合字体配置与读取一致性

2026-09-10；v4.0 开发工作包，不是 Stable 或地图发布证明。

## 本轮实现

- 包清单可选 `font_profile`，仅允许 `cjk-v1` 和 `cjk-mongolian-emoji-v1`。不填写时保留旧行为，不向旧清单补字段，避免改变其摘要。
- 新组合固定为 CJK、Mongolian、Emoji 三字体，明确区分样式字体数组、PBF 嵌入名称和服务端存储目录。
- 前端样式生成器、样式依赖校验、联合渲染校验、库存与字形读取使用一致的配置。未知配置、混用旧字体和组合字体均拒绝。
- schema2 读取除了校验文件自身，还必须匹配清单中对应字形项的名称、大小和摘要。清单外分段返回 404，摘要不一致返回 503。
- 授权撤销后不能继续读取；旧地图保留原字体协议。当前生产地图和正式案件未修改。
- 固定 WASM 字形生成器支持原有三参数模式与完整的两种补充字体参数；逐字体固定摘要，输出新目录，不覆盖旧目录。组合模式生成 256 个 BMP 分段及 `127744-127999` 补充分段。

先写失败测试再实现。独立审查复现了“更新文件和 artifact 摘要但不更新清单仍可读取”的缺口；补充两项 API 测试后修复，独立复核通过。

- 后端定向 139 项通过；本次测量 `map_font_profiles` 行覆盖率 100%，`map_glyph_service` 96%，不是全项目覆盖率。
- 后端全量 843 项通过、1 项跳过（33.57 秒），包括链条回归。跳过项需要一次性 PostGIS 环境，不能视为本次已通过 PostgreSQL 验收。
- 构建脚本 122 项通过（3.68 秒），包括实际 MVT、PNG、PBF 的组合整包校验与混用拒绝。
- 前端字体样式 18 项通过，类型检查与生产构建通过。保留既有大包警告。
- 独立审查确认清单绑定修复和生成器内存生命周期；缺失的静态工具未计入通过。
