# 两市矢量地图全量标签审计

2026-09-10；v4.0 开发验证，不是发布审批。

## 本轮实现

在现有矢量文件校验的同一次完整解码中，增加可选标签字段审计。命令行使用 `--audit-public-labels` 开启固定预设：

- 图层：`place`、`poi`、`transportation_name`。
- 名称优先级：`name:zh`、`name:latin`、`name`。
- 与页面 coalesce 语义保持一致：空字符串不再回退；非字符串标签明确报错，不静默转成字符串。
- 遍历全部瓦片。相同压缩内容命中缓存时，仍累计标签次数，不把缓存当抽样。
- 仅保留一份全局码位集合，缓存不保留各瓦片的重复字符集合。
- 原有调用不启用审计时保持输出契约；没有改变正式数据库、现用地图或发布状态。

字段选择审计不是完整样式求值，不应用缩放可见性、过滤、碰撞和布局规则；统计为全瓦片标签出现次数，不是独立地名数或屏幕实际显示次数。`shaping_verified=false`，不据此断言连写正确。
