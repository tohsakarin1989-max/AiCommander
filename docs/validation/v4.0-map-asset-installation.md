# v4.0 地图资产持久安装验证

本记录不是 Stable 发布声明。基线仍为 v3.6.0-stable。

## 已接通链路

后台导入任务在重组和渲染校验成功后，将完整资产按清单摘要安装到
`MAP_PACKAGE_ROOT/bundles/<sha256>`，之后才清理临时重组目录。
安装回执写入导入任务的 `report.installation`，不创建已接受地图，
不修改 current，不把安装成功当作业务验收通过。

安装时逐文件核验大小和 SHA-256；先写独立暂存目录，再原子重命名。
同包并发由文件锁保护，重复执行重新校验已存文件而不覆盖。
安装失败时任务失败；旧地图继续保持。失去租约的任务不能覆盖新任务结果。
