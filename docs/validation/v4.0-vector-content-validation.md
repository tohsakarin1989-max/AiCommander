# v4.0 矢量地图内容验收工作包

日期：2026-09-10。状态：单项矢量资产内容校验已实现；尚未进入正式地图包集、发布事务或浏览器离线验收。版本仍为 v3.6.0-stable。

## 本轮实现

`backend/app/services/vector_map_validation.py` 供隔离地图后台任务调用，不由案件保存接口或核心 API 启动。复用构建环境固定的 `mapbox-vector-tile==2.2.0`；核心运行依赖未增加 GIS 解码库。编码契约参考 [MBTiles 1.3](https://github.com/mapbox/mbtiles-spec/blob/master/1.3/spec.md) 和[解码库说明](https://github.com/tilezen/mapbox-vector-tile)。

校验过程：

1. 拒绝符号链接和非普通源文件；逐块计算摘要并复制到独占临时目录，源文件不改写。只扫描摘要一致的私有副本，避免验证后重新打开变化的源文件。
2. SQLite 只读、禁用受信任 schema，检查数据库完整性、元数据重复、格式、声明边界及层级。
3. 检查瓦片坐标有效性、重复坐标、全部原生层级是否存在；逐张读取全部存储瓦片。
4. 有界解压 gzip，拒绝截断、尾随内容、超限解压；校验 MVT 必填字段、图层编号、属性索引、几何命令状态及完整解码。多边形必须闭合，线段至少两点。
5. 返回瓦片、非空瓦片、显示要素、图层与层级计数，并始终标注 `publish_ready=false`。

边界：源文件最多 8 GiB、最多 200 万瓦片，单张压缩内容 2 MiB、解压 8 MiB，单张最多 10 万要素。当前项目解码契约为 MVT version 2、extent 4096。默认 900 秒协作超时；复制、SQLite 查询、瓦片解码后及返回前检查时间。单个解码期间的强制终止仍须由隔离 Worker 的进程级硬超时实现，不能把该函数检查等同于硬超时沙箱。

## 真实两市候选扫描

输入：`backups/map-foundation/v4-source/20260908/vector-candidate-v1/two-city.mbtiles`。

- 大小：149,225,472 字节。
- SHA-256：`ba4bac705eeab75683cfbf8c9eb8747238c67a825e0fded769a7659e2c6ef5ef`。
- 瓦片总数：788,288；含要素瓦片：395,082。
- 显示要素计数：1,807,887。该数字跨层级重复计数，不是现实设施/道路总数。
- 原生层级 6—16 均存在；层级瓦片数依次为 4、9、21、57、212、751、2,851、10,731、36,868、147,472、589,312。
- 观察到 16 个图层，包括交通线、道路名称、建筑、地名、水体、水系和边界。
- 收紧几何状态机后全量复验耗时 17.45 秒，为本机校验耗时，不是地图冷启动性能，也不是目标服务器数据。

复现（使用固定地图构建环境）：

```sh
python scripts/verify-vector-map.py \
  backups/map-foundation/v4-source/20260908/vector-candidate-v1/two-city.mbtiles \
  --sha256 ba4bac705eeab75683cfbf8c9eb8747238c67a825e0fded769a7659e2c6ef5ef \
  --bounds 121.9954687124249 45.11031168347853 127.06370572422722 49.19124651842884
```

退出 0 仅表示该矢量文件内容校验通过；退出 2 表示内容、依赖或读取失败。命令不联网、不改正式库，不发布地图。会创建并清理本次私有临时副本。

## 测试与剩余门槛

按 Python 测试规范先复现再修复。专项 37 项通过，服务覆盖率 91%；覆盖真实 protobuf 损坏、压缩炸弹、重复坐标、层级缺失、几何类型正例、未闭合多边形、无有效线段、CLI 损坏失败、深层 JSON 受控失败，以及最后一张瓦片超时不得成功。独立评审指出的几何容错、末块超时及深层 JSON 异常问题均有复现用例并已修复。核心后端回归 631 项通过、1 项跳过；该跳过不作为真实 PostgreSQL 验证。

此项不证明地理覆盖完整，不证明道路拓扑可计算，也不证明断网浏览器能正确显示。仍需将道路引用完整性、地图范围覆盖、字体/样式/图标闭包、地名索引来源绑定分别校验，并接入完整 schema 2 注册、原子发布、回滚与各页面。没有修改正式地图、案件或 GitHub Release。
