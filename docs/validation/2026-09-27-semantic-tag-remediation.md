# 业务精简接续检查与整改

日期：2026-09-27。源码版本仍为 `5.4.0-stable`；本记录不构成 GitHub 发布、目标服务器部署或真实模型验收。

## 已整改

1. 先用隔离合成案件复现：`未发现罐车`、`无罐车` 被旧标签算法转成肯定罐车标签。旧标签现复用共享词项分类器，明确陈述、否定、待核和肯否并存分层；保留字段哈希、原文位置或结构路径。词项自身的“无牌”“未上锁”“无照明”不会被当成自我否定。
2. 原始字段分开处理，历史模型输出、派生特征、人工标签和经验总结不反向成为原文。结构对象的键、布尔值和编号不生成肯定词项；未知父键、疑似状态、未确认标记以及同对象/祖先描述中的否定均保守保留待核。
3. 经验卡、旧兼容报告和模型上下文同步保留信息缺口，非肯定观察不计入自动车辆/工具/防护特征。前端在标签和经验预览中提供折叠的原文依据，数值标为规则支持度而非概率。
4. 未登记村屯不推定偏远；技防点位缺失或距离远不推定防护不足；直线近路改称“邻近已登记道路”。涉油数量少不再直接命名为“转运”。未调整道路授权、路由引擎或地图数据。
5. 新预览不继承历史卡的人工确认状态；新经验版本不覆盖案件 JSON 中的历史卡。兼容批量生成遇到已确认/归档旧卡时保留原卡。确认、归档与历史报告均保持显式人工操作和现有权限。
6. 事件页旧评分档案不再显示成当前“高风险区域”，注明历史高等级档案最多五条；读取错误/加载分别显示真实状态。静态追踪未发现生产页面继续调用本轮所查的 410 退役接口；未使用的兼容封装未扩大删除。
