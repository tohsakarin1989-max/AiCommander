# v9.5 实际台账适配：发布验证

日期：2026-10-09。基线：v9.4.0-stable。本文只包含可公开的契约和验证边界，不包含真实案件、人员信息、样本分布或原件路径。

## 样本核对与安全范围

真实台账仅在本机以副本调用只读解析、规范化和规则画像进行核对，没有导入业务数据库、调用外部模型或修改源文件。由此确认的结构问题包括重复备注、无表头补充列、不同用途的分类列、日期来源不一致及数量单位缺失。公开回归全部另造合成记录。

来源范围可定位只能证明引用准确落在原文，不能称为语义准确率；本轮未开展标注集精度评价，也未声称覆盖所有历史台账格式。

## 发布前验证范围

| 路径 | 核对要求 |
| --- | --- |
| 台账导入 | 显式预设、重复备注／无名列保留、普通导入兼容、日期和单位不猜测、原文件和行位置 |
| 原件及来源 | 失败重试保留原行、成功行幂等、复制原行随原件撤销隐藏、当前权限检查 |
| 本地及模型候选核对 | 时间角色、相对日期切换、油量对象／环节／精度、移交对象及未完成状态 |
| 语义画像及历史分析 | 处置与作案行为分离、肯否与原文引用、单位／设施同名词、规则版本参与更新 |
| 页面与材料 | 导入预览、原行展开、现场处置画像、Word/PDF 共用内容模型及 DOCX 回归 |
| 保留业务 | 案件保存预检、批量复核、来源修订、原有通用导入及生产配置 |

本轮独立复核发现并修正三个问题：数量区间／上界被当成单值、后置未获同意被当成已移交、前一事件时刻跨相对日期绑定。合成回归同时覆盖本地提取和模型候选二次核对。独立复核重放 6 个反例及 9 个相邻正向场景，通过，未发现新的高优先级问题。
