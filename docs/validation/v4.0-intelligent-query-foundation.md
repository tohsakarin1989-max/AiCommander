# v4.0 受控智能查询基础验证

当前仍是 v3.6.0-stable 发布基线。以下是开发中基础服务，不是普通用户可用能力或 Stable 声明。

## 本轮实现

- 五类白名单只读工具：案件查找、地点设施查找、案件条件计数、等长时间窗比较、已有成果运行汇总。
- 案件检索复用 CaseSearchService；地名检索复用当前授权地图快照与本地索引。
- 每次执行要求明确绑定当前读取权限；用户指定厂区不能扩大授权范围。
- 参数拒绝未声明字段，不接受 SQL、脚本、URL 或任意文件路径。
- 返回工具生成的数据卡、来源、查询条件、授权范围、查询时刻及工具版本。
- 内网模型只选择下一工具或停止，不直接生成答案和证据；最多8次工具调用。
- 支持模型超时、步骤预算、取消检查、缺数据及异常的明确结果。
- 复用模型注册表 AGENT_MODEL_ID 和 ModelFactory 的 raw 分级：原始问题和工具数据禁止发送非受信任外部端点。

## 验证

51项工具、循环、现有案件检索和大屏统计测试通过。
工具语句覆盖率98%，循环88%。包括全授权库110条统计、跨辖区隔离、
公共索引故障不冒充空结果、左闭右开等长窗口、UTC边界溢出拒绝、
缺失/停用/外部模型拒绝、非法工具、模型虚构答案字段拒绝、取消与超时，
以及最后一次模型返回超时不能标记为成功。

模型响应使用测试替身，不计作真实配置模型端到端验证。
只读检查当前本地注册表：3个活跃模型，0个符合当前受信任内网端点配置；
本轮未修改配置、未调用外部模型，也未输出密钥或端点详情。

## 后续接通项

- 查询任务持久化、当前权限重新绑定、任务创建/查询/取消接口及运行轨迹落库。
- 页面卡片、来源跳转、自然语言问题与工具结果的业务流程。
- 已有研判正文的证据范围核验与汇总；当前只提供运行数量、状态和版本，不虚称完成正文总结。
- 外部模型路线需要独立的安全特征转换；当前禁止原始问题外发。
- 数据库执行期限及后台隔离：当前循环可限制模型等待与步骤间检查，不能强制打断同步数据库查询。
- 真实内网模型联通与全链路验收，以及展示入口。
