## 当前接入缺口与下一实施项

1. `map_glyph_service.py`、`map_glyph_validation.py`、库存存储键与样式闭包目前只接受0—65535范围。需要保留BMP兼容，按实际需要增加受控的补充平面分段，不能接受无限范围或未登记资产。
2. 现有生成器只接受固定CJK单字体。需要明确字体优先级、复合字体标识和逐字体许可；不得静默换掉原中文字体或伪造字形身份。
3. 已安装MapLibre的 `charInComplexShapingScript` 当前只识别Arab；它并不能证明Mongo字形替换/定位已执行。需要使用真实蒙古文标签对连写与布局作浏览器验证，不能以字符编号齐全替代。
4. 当前缺字清单含格式选择符与两个非BMP字符，验证需要区分控制字符、可见字形及复杂成形。
5. 通过实际字体生成、全标签核验和浏览器显示后，再重建完整包；本轮不改`font_coverage_verified=false`。

本轮改变了下一步的实现依据：已找到真正覆盖所需字符的固定字体，排除了名字看似合适但并未覆盖目标符号的Symbols 2字体。尚未完成接入或登记发布。
