# 两市完整道路与限制依赖提取

2026-09-10；v4.0 路网前置工作包，非 Stable 或机动车可达性验收。

## 交付

新增 `scripts/extract-public-roads.py`，独立构建候选，不访问业务数据库，不替换 current。

1. 严格绑定原始源及区域文件摘要。
2. 使用线与实际提取多边形相交判断，不能只判断道路端点是否在范围内。
3. 保留相交 highway 线要素的完整节点顺序、坐标和原始标签，不在行政边界处截断道路。
4. 加入关联限制及全部成员；新增路段的节点也参加下一轮限制选择，至依赖闭合。
5. 缺任何相关节点、路段或嵌套关系即失败，不删除异常限制使验收变绿。
6. 从原始对象写出独立PBF后实际读回，验证对象集合和引用；最后生成清单。

每次使用全新目录，临时候选失败时清理，原始文件和旧成果保留。
最多64轮依赖扩展，超限明确失败，不把截断结果当成完整输出。
