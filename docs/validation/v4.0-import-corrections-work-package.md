# v4.0 第三工作包：导入失败行修正

验证日期：2026-09-10。当前基线仍为 v3.6.0-stable，不构成 v4.0 或 v4.5 发布声明。
整体交付目标按批准路线推进至 v4.5，每个中间版本独立验收后统一更新 GitHub。

## 已实现

- 共用逐行校验与时间解释服务；默认 UTC 兼容旧调用，显式北京时间仅解释无时区输入。
- 导入页面增加时间解释选择，更改后清除预览，预览和写入使用相同参数。
- 原回执中直接选择失败行修正；只传更改字段，写入期间禁止关闭、更换文件和修改配置。
- 响应丢失或版本冲突时不自动重试；刷新按服务器实际结果恢复父级总数、错误清单和失败行列表。
- CaseImportRow 保存原始单元格、当前修正值、状态、版本和修正历史；不覆盖成功案件。
- GET /api/case-imports/batches/{id} 返回失败行；POST /api/case-imports/batches/{id}/retry 仅修正失败行。
- 成功源行禁止改写；重复修正不重复建案；陈旧版本拒绝；权限和辖区沿用现有隔离。
- 批次写锁保护不同失败行并发纠错，锁后刷新对象；拒绝请求也回滚释放锁。
- 案件、Outbox、行状态和汇总回执一起提交；提交失败回滚。
- 增量迁移 c508d9e0f162，前置 b4f7c8d9e051。旧批次无源行记录时不伪造可重试数据。
