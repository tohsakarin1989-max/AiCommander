# v4.0 查询任务持久化

当前仍是 v3.6.0-stable 发布基线，本记录不表示普通用户入口已开放。

## 接通内容

复用 AgentRun/AgentEvent，实现创建、读回、取消、认领、完成和过期转换，
并将上一工作包的 run_query 与实际业务工具接通。记录历史问题、数据卡、
工具轨迹和查询时间；返回结果明确标为历史查询快照，不冒充当前实时统计。

每次访问重新读取当前账号并绑定只读辖区；任务仅所有者可访问。
权限、账号会话版本及可见案件/设施/地图快照成员发生变化时，旧结果拒绝读取。
这一成员校验仍需在目标数据规模下测量性能，尚未用修订号缓存替代。

取消使用状态条件更新；原认领者的迟到结果不能覆盖取消或其他终态。
模型等待期间撤权或停用账号后，任务以系统取消结束，不保存返回结果。
超过120秒的完成提交拒绝；提供过期状态转换，尚需队列维护任务接入。

## 集成修复

复用表后，旧 Agent 接口曾可绕过新所有权检查读取查询问题和结果。
已用 HTTP 测试复现，随后在旧列表、详情及其事件/取消/重放入口排除新查询类型；
旧运维汇总和证据图直接读取同样排除，防止从旧入口绕过新访问策略。

## 验证

- 查询持久化12项测试通过，包含实际工具与数据库读回（模型为测试替身）。
- 查询循环/工具、旧Agent运行、运维汇总、证据图及链条相关回归合计90项通过。
- 前端类型检查及生产构建通过；现有大文件块警告仍存在。
- 差异空白检查通过。未修改生产业务数据库，未调用真实外部模型。
