## 实现取舍

采用“后台目录摘要 + 当前权限下只读组合”。新增 `facility_derived_summaries` 仅存可重建的生产目录派生资料，不另建资产主库，也不将跨案摘要复制进全局缓存。

普通 Worker 每 60 秒按最久未检查顺序核对最多 25 个设施目录。有变化才增加摘要版本，并保存变更类别。它独立于 Agent Lab、外部模型和道路服务。队列不可用时，当前档案仍可读取，摘要明确显示待更新。

案件、画像、事件、道路和成果关联每次查看时从已有数据按当前权限重新组合，不重新抽取原文或调用路由。全档案及各部分返回内容版本，输入改变后即可对比哪一部分变化。这是保守实时重组，不宣称实现了精准依赖增量。

生产、明确记录、空间邻近、候选、事件、成果、入口、技防、历史条件分开呈现。资料受限时不返回该部分的项目或数量；历史成果仍通过现有来源鉴权，不因过去看过就继续开放。

时间参数采用 `start_date <= 时间 < end_date`，保留时刻与 UTC 偏移，不由后端偷偷扩展一整天。
