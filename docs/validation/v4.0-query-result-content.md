# v4.0 已有研判成果正文查询

2026-09-10。补齐五类基础查询中的“汇总已有研判成果”，不新增研判算法。

## 交付行为

- 继续按当前授权案件、完成时间和厂区筛选运行；统计口径和分页上限不变。
- 返回已有摘要、最多三项候选、支持证据、反向证据、信息缺口及画像/地图/算法版本。
- 分数标为规则支持度，不暴露未经校准的 confidence 作为准确概率。
- 查询逐项检查当前案件、画像、地图快照、冻结要素和当前设施权限，不以ORM身份缓存作为授权证据。
- 未知引用、已删除证据、跨范围证据、错配快照均不展示对应候选；同时隐藏可能包含相关内容的运行摘要及原始运行缺口。
- 输入版本不可读取时仅提供不可用说明；部分隐藏返回partial，不把它描述为没有关联。
- 前端复用查询结果卡片分层展示正文，保留旧元数据查询回放，并提示重新查询。
- 不生成新结论、不写正式案件、不调用外部模型。
