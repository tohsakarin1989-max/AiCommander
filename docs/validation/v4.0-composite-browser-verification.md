# 组合地图候选浏览器验证与请求白名单修复

2026-09-10；真实 Chrome + 隔离公共数据页面，不是正式后端地图发布证明。

## 实际发现与修复

首轮直接读取新候选包的固定清单、样式、矢量数据库和字形，清单及实际资源先核对摘要。浏览器显示了地图文字，但字形请求数量为 0，检查失败。

排查当前 `offlineMapRequest` 发现前端只放行旧 CJK 字体路径。组合字体被拦截后，已安装的 MapLibre 使用本机字体回退；因此截图有文字不能证明离线字体生效。

按 tdd-workflow 先补回归：组合字体的两种逗号编码方式失败；然后将白名单与样式中的固定字体栈共享。仍精确限制两种已登记字体，拒绝未知字体、额外字体、非法百分号编码和编码路径分隔符。后端继续验证区间范围、对齐、清单身份和字节摘要。

## 复测证据

新建隔离浏览器上下文，非本机请求全部拦截；使用新候选 `complete-candidate-v2` 的真实资源。四个入口：案件地图、选点地图、时空热力地图、辖区资产地图。

- 四个入口完成加载、截图和卸载。
- 20 次瓦片请求，295 次实际组合字形请求，非本机请求 0 次。
- 实际使用本地 MapLibre Worker。
- 样式故障时选点禁用、按原快照重试、不重复获取 manifest。
- 注入 WebGL 缺失后正确清理，Leaflet 基础操作未崩溃。
- 单元回归 37 项通过；类型检查、生产构建、差异检查与独立只读审查通过。
- 首次类型检查发现测试中的 `replaceAll` 超出项目目标库，改为等价正则替换后重新通过；链条回归 4 项通过，生产构建保留既有大包警告。

截图：`output/playwright/composite-v2-fixed/cases.png`、`picker.png`、`heat.png`、`assets.png`。实际查看案件地图截图，大庆市、齐齐哈尔市等中文地名和地理图层可见。未将非中文复杂文字连写或所有缩放级别的布局列为通过。

Playwright CLI 包装器尝试获取依赖时受网络解析限制；复用已安装的 Playwright 和项目原有检查脚本完成了真实浏览器验证，没有以模拟浏览器响应替代浏览器执行。

## 范围限制与下一项

测试页面来自本机 Vite。API 元数据、鉴权响应和资源传输由隔离脚本接管；资源字节真实，但没有经过正式 FastAPI 登记、发布链路。结果明确标记 `backendPublicationVerified=false`。这不是生产构建端到端、正式授权验收或完整断网发布验收。

原候选和 current 未修改。下一项应接通正式后台登记、发布/回滚和完整后端浏览器验收，并继续 v4.0 五类智能查询及展示工作，不将本次四组件测试视为 Stable 完成。
