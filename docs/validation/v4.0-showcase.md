# v4.0 展示入口：隔离业务闭环

2026-09-10；仍是候选开发状态，不是 Stable 发布声明。

## 已实现

- `/showcase` 菜单“展示”，沿用登录；仅当前有效管理员、分析员可访问。
- `ENABLE_SHOWCASE=false` 默认关闭，开发/生产环境示例及生产 Compose 已接线。
- 三个固定合成场景：正常研判、缺少坐标、注入模型超时。
- 每次新建独立内存 SQLite；调用真实 `CaseService`、`CasePipelineService`、
  `CaseInsightService`、`DeploymentAdvisorService`。不接受正式案件ID、任意文字、文件路径、URL或模型配置。
- 案件保存使用 `commit=False` 后自行提交，不执行共享向量库索引；不修改全局配置。
- 模型故障只向真实 `AgentRunExecutor` 注入超时叙述器，没有外部网络调用。
- 主库仅复用 `AgentRun(task_type=showcase)` 存合成输入摘要、结果和轨迹；无新增数据库迁移。
- 业务运行指标、旧Agent入口及证据图检索均排除该任务类型，演示不会挤占真实成果列表。
- `POST /api/showcase/runs` 接收场景与UUID请求编号；重复编号复用记录，改场景拒绝。
- `GET /api/showcase/runs` 返回当前账号最近20条；`GET /api/showcase/runs/{id}` 返回历史回放。
- 每账号每分钟最多3次，每进程最多2个并发执行。运行120秒未归档，在后续访问时标为expired；
  晚到归档受CAS保护，不能恢复过期记录。此门槛不等于强制终止线程。
- 实时规则结果、历史回放、故障注入分别标识。原始事实摘要核对、反向证据、信息缺口、
  输入摘要及算法版本可见；规则支持度不称为准确概率。
- 授权拒绝后清除结果并取消历史查询，迟到响应不可回填缓存。

## 验证

- 执行器4项测试：真实候选和反向证据、缺坐标不造候选、真实降级、每次独立数据与共享索引禁用。
- API5项测试：登录/角色/关闭/所有者、幂等、配额、输入白名单、失败记录、过期CAS、业务统计隔离。
- 与运行观测及生产配置相关回归共41项通过；新增执行器100%、接口98%、合计99%语句覆盖。
- 前端QueryClient专项证明：取消后迟到历史响应不回填，其他账号缓存不受影响。
- 类型检查及生产构建通过；既有大包体积警告仍存在。
- 实际Chrome + 完整FastAPI + 真实登录 + 独立临时库，三个场景实时运行通过，
  历史回放及刷新后3条记录保留通过，1440/768宽度无横向溢出，页面错误0、公网请求0。
- 三个业务场景未模拟API；另单独注入403验证清屏，不能把该注入当作真实撤权后端测试。
- 截图：`output/playwright/showcase/desktop.png`、`narrow.png`；已目视核对。
- 复核修正：简报采用真实成果生成时刻；轨迹区分调用返回与业务降级；
  归档中断不再永久running；展示不污染业务指标；权限拒绝取消在途查询。

## 复测入口

1. `AIC_DISPOSABLE_SHOWCASE=1 backend/venv/bin/python scripts/serve-isolated-showcase.py`
2. 前端使用 `VITE_API_PROXY_TARGET=http://127.0.0.1:18050`，监听本机13043。
3. `node scripts/verify-showcase-ui.cjs`（可用`AIC_PLAYWRIGHT_MODULE`指定已有依赖）。

后端脚本切到临时目录并清空继承环境，不加载操作者`.env`；仅监听本机18050，
停止后删除其临时数据库。专用测试账号只存在于一次性环境。
