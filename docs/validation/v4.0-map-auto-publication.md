# 地图自动发布闭环

## 配置与行为

`MAP_AUTO_PUBLISH_AREA_IDS` 默认为空（关闭）；管理员在部署配置填写已确认的厂区ID，
例如 `1,2`，最多16个且不可重复。生产Compose已传递该配置。
地图Worker每轮处理验证任务后，继续领取已完成渲染验证、尚无自动发布结果的任务。

流程：持有租约 → 检查上传管理员仍有效且拥有厂区manage权限 → 登记全资产 →
构建快照 → 在发布事务内复查权限及租约 → 切换current → 写入每厂区结果。
后台崩溃后35分钟租约到期可恢复；已发布快照复用，不重复创建或重复切换。

- 只有当前管理员授权的配置厂区可更新；空作者、停用账号、撤销授权均拒绝。
- 同一来源的新时间版本才能自动替换已有current。旧版本、同时间版本、来源改变或时间无法可靠比较，交由管理员处理。
- 自动比较要求已有版本和候选的source_version为带时区ISO时间；历史非时间版本不被猜测排序。
- 首次发布仍须通过既有厂区覆盖、冲突和全资产校验。
- 一厂区失败不撤销其他厂区已完成的发布；失败厂区保持旧current并记录attention_required。
- 故障结果不无限自动重试；管理员解决异常后可使用现有登记/构建/发布入口。
- 停用时清空配置并停止/重启地图Worker；人工回滚前先停用自动更新，避免后续候选再次更新。
- 此能力只发布离线显示底图，不启用机动车道路计算，不修改案件事实。

管理员通过 `GET /api/map-package-imports/{id}` 获取 registration 与 auto_publication，
不再需要对正常包逐个执行登记、构建和发布。普通用户不增加操作。
