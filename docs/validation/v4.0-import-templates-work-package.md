# v4.0 第四工作包：字段映射与导入模板

日期：2026-09-10。当前发布基线仍为 v3.6.0-stable，本工作包不是 Stable 发布声明。

## 交付内容

- 列名识别接口返回表头、工作表目录和建议映射，不返回案件行值；继续执行上传、解压及行列限制。
- 说明封面页没有数据时仍可取得工作表目录；正式导入继续拒绝无数据表。
- 可视化字段映射，明确“不导入”值，清除自定义映射；修改配置后旧预览失效。
- 按厂区权限保存不可变模板：名称、工作表、表头行、时间解释、字段映射；不保存案件行。
- 模板只用于解析配置，不绑定或自动改变案件厂区，不绕过导入前校验。
- 界面显示本厂区可见模板；模板列表接口目前最多返回最近 200 条授权模板。
- 新增迁移 d619e0f20373，前置 c508d9e0f162，仅新增模板表，不重写原案件。
