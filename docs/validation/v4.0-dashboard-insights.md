## 行为

- 按同一授权厂区和完成时间窗口读取已有研判，案件统计仍按案发时间。

- 总关注项最多三项；有案件类型数量增加时保留至少一项数量变化事实。
- 展示候选解释、支持证据、反向证据、信息缺口、版本和引用；复用现有证据当前权限核验。
- 案件链接独立打开详情，已有坐标可触发地图定位；不创建巡逻、调查或处置任务。
- 候选检索最多50份（另取1份判断截断），明确提示检索范围；案件与研判总量统计不截断。
- 普通智能查询的历史成果仍可按权限读取，不受大屏只选当前输入的规则影响。
