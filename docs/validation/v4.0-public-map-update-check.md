## 交付及边界

脚本只读取自身公开更新状态，不导入业务应用、不载入业务数据库、模型密钥、案件或生产图层。
请求只到三个固定HTTPS地址，禁用继承代理和重定向，响应不超过2KiB，每次15秒超时。
输出变化提示，不直接把MD5当作安全发布校验；后续下载必须冻结同一日期来源并走SHA256和现有验包流程。

systemd月度模板已提供，但本机没有安装、启动或实测Linux定时服务。
候选地图包构建与内网交换仍由既有受控流程处理，本工具不会自动更新内网current。
