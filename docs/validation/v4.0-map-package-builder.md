# 可重复的公共地图制包入口

2026-09-10；v4.0 开发工作包，未发布Stable、未写入正式地图登记。

## 实现

`scripts/build-map-package-set.py` 接收由公共构建区管理员维护的本地recipe，输出全新传输目录。
只使用标准库及项目纯文件模块，不加载业务数据库、SECRET_KEY或模型配置，不联网。

recipe沿用schema 2清单字段，但每项资产以 `path` 替代 `chunks`：

```json
{
  "name": "two-city.mbtiles",
  "role": "vector",
  "path": "/absolute/canonical/public-source/two-city.mbtiles",
  "size_bytes": 211681280,
  "sha256": "57ac644ba0ce3a57f88339839f7a737bfb797ae324a4f4afdeadf2a5c34e4b4d",
  "license": "ODbL-1.0",
  "attribution": "OpenStreetMap contributors"
}
```

以上只是资产示例，不是可执行完整清单；必须提供全部七类必需资产和实际许可声明。
输入必须是绝对规范路径，逐级拒绝符号链接；文件必须是固定大小、固定预期摘要的普通文件。
分片不超过16MiB、最多8192片、包集总量不超过8GiB；先校验清单再开始创建输出。

```text
python scripts/build-map-package-set.py /absolute/public-recipe.json /absolute/new-transport
python scripts/verify-map-package-set.py /absolute/new-transport
```

制包逐片计算摘要，并验证整文件预期摘要；完成后最后写manifest。
失败只清理本次新建目录，不覆盖旧目录、原始来源或已发布地图。
相同输入生成字节一致的manifest与分片；路径不进入传输manifest。

## 许可和隔离

schema 2增加可选 `license` 资产，随其他资产一起分片、校验和重组。
字体OFL等完整文本不再需要误标为边界文件；旧包读取兼容。
此类型只负责保留实际文本，不自动证明许可合法、署名完整或数据可出域。

该入口不注册HTTP路由，不允许用户提交任意本地路径。
`contains_internal_data=false`只是声明，不是敏感数据扫描器。操作环境仍须严格限定为公共来源目录；不得挂载案件、生产井位或技防数据。

## 实测

- 制包专项15项：完整读回、重复构建一致、摘要/大小错误、文件及父目录符号链接、FIFO、既有目录、无业务配置CLI等。
- 新增制包服务覆盖率92%；不代表整个项目覆盖率。
- 使用实际MVT、PNG、字形和SQLite解码器的合成小包，完成制包→重组→联合解码，许可字节保留一致。
- 构建脚本全集111项通过（2.43秒）；真实隔离地图环境的CLI help通过，无SQLAlchemy或业务配置依赖。
- 相关后端96项通过（4.78秒）；测试夹具存在SQLite连接未关闭警告，未表述为零警告。
- 独立复核在隔离环境实际运行CLI制包通过；此前业务配置依赖问题已修复。
- 这不是两市完整实物包验收：尚需整理全部真实资产recipe，实物制包、许可与字体覆盖检查、登记发布及断公网冷启动。

制包和重组均返回 `publish_ready=false`；未将传输完整性自动提升为地图可用性或路网通行正确性。
