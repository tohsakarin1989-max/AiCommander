# v4.0 样式本地依赖与快照绑定

2026-09-10。本项补齐 schema 2 内容验收的一环，未导入真实包集、未切换正式地图，也未完成浏览器断网验收。

## 实现

新增 `map_style_dependencies.py`：

- 包内样式使用固定逻辑资源地址：`aic-map://public/{z}/{x}/{y}`、`aic-map://glyphs/{fontstack}/{range}.pbf`，可选 `aic-map://sprite`。
- 仅允许单个 public 矢量数据源；数据范围及原生级别与包清单一致。禁止 TileJSON URL、其他数据源、外部字形、导入样式及 font-faces。
- 文本字体固定为 `Noto Sans CJK SC Regular`，包括 formatted text 中的覆盖项；包内须声明全部 256 个 BMP 字形范围。
- 使用图标或纹理时必须是已登记的常量名称；sprite 同时要求普通和二倍资源，清单资产名为 `sprite.png`、`sprite.json`、`sprite-2x.png`、`sprite-2x.json`。当前基础样式未使用 sprite。
- 来源图层与解码资产提供的图层集合核对。未知图层、缺失字形、未知图标、HTML attribution、过深 JSON 和非法字段均按受控错误拒绝。
- 绑定时只替换三个已验证资源字段，并同步 `aic:snapshot-id`，不做任意文本替换，不改变原始包内样式。

## 验证

按测试先行规范实施；后端专项 28 项通过，模块覆盖率 91%。独立 Python 评审已通过初始 24 项，随后补充旧快照 metadata 更新及非有限数测试。`NaN`、`Infinity`、`1e400` 均不得进入绑定后的 JSON。

跨语言测试直接编译当前 `frontend/src/components/Map/offlineVectorStyle.ts`（不复制另一套样式），先执行安装版本的 MapLibre 官方语法校验，再转为逻辑地址，通过后端本地依赖规则并重新绑定，最后再执行官方语法校验。14 层样式两次语法检查无错误。地图工具测试累计 60 项通过。

跨语言测试使用合成清单声明来检查当前样式兼容性，不验证真实字形文件、sprite 图片或两市地图覆盖。`source_layers` 和 `sprite_names` 必须由后续完整导入器的资产解码结果提供，不能由客户端任意声明。

本轮后端全量回归为 675 项通过、1 项跳过（24.11 秒）；之后新增三个非有限数回归并单独通过。未将需真实 PostgreSQL 条件的跳过项记作通过。
