## 通过项目

`scripts/verify-dashboard-map-integration.cjs` 使用实际认证HTTP接口，不模拟API响应：

1. 大屏完整统计返回1起案件、1口登记井、1份成果。
2. 关注候选包含实际支持/反向证据，其地图快照ID与当前地图manifest一致。
3. 清空浏览器缓存后，中文样式、瓦片和字形通过内网接口成功加载。
4. 点击候选案件定位后实际地图显示该点位；切换登记井图层显示1口井。
5. 案件链接进入 `/cases?caseId=1`，实际详情API返回200，详情里的候选地图也完成矢量加载。
6. 浏览器公网请求0、页面异常0、API 5xx为0。
7. 后端连接公开地址的TCP探测返回101（网络不可达），未发送业务内容。

首次检查误将SPA页面空闲当成详情接口已返回，断言失败；已改为等待实际详情响应。
截图又暴露详情地图尚未就绪，随后补上矢量画布及加载状态断言，再完整复跑退出码0。
辅助奖金接口出现403，不将其计为成功；未阻断案件详情和地图，奖金功能不在本次通过范围内。
