# 案件录入与中断恢复简明指引

适用：v7.1 录入工作包。功能是否已开放，以实际安装版本和账号权限为准。

## 平时怎样录

1. 从首页“录案件”进入，也可从案件页“新增”进入。先填常用内容，需要时再展开补充字段；不知道的时间、位置、数量不要编造。
2. 已有案情文字可以用于辅助填表。核对原文出处和肯否表达，提取结果不是已确认事实；“规则辅助”不代表调用了模型。地点可从有权限的设施中选择，同名井看编号和所属范围。
3. 尚未填完时，主动点“保存私有草稿”。**系统不承诺所有键入内容都已自动保存。** 确认保存成功后再关页，下次在草稿入口继续。私有草稿不会出现在正式案件和统计里。
4. 确认后保存正式案件，成功可直接查看本案。后台画像或其他分析尚未完成时，仍可继续录入、查询和使用现有资料，不需要另录一份画像。

## 出错或离开时怎样做

| 提示 | 正确处理 |
| --- | --- |
| 明确保存失败、字段不合法 | 当前输入保留，按提示修改后重试。不要关闭页面丢掉尚未保存的内容。 |
| 提交结果未确认 | 先核对结果，必要时使用原请求重试。不要另开一条相同案件“再存一次”。 |
| 他人或另一页面已更改 | 比较当前正式记录与本页输入，决定取用哪一项；不要以为本页内容已自动保存。 |
| 另一页面已把草稿转成案件 | 打开比较结果。另存私有草稿不等于又建一案，正式保存仍需明确确认。 |
| 草稿不可恢复 | 可能已到期、权限改变或目标案件已不存在，不能据此认定“没有提交过”。联系管理员核对，不绕过权限。 |
| 模型未配置或不可用 | 继续手工、规则辅助或表格录入，不必等待模型。 |

草稿默认保留 7 天，单位可另配 1—90 天；超期后不能继续恢复。退出或换账号后不能看到前一个账号的草稿。服务器不可达时，页面未保存的内容并不等于已有服务器备份。

## 导入表格怎样续做

首次选好工作表、字段和时区，后续复用适用模板。国内无时区数据先确认业务时区；不要为了导入成功随便选 UTC。

导入后看成功行与失败原因。关闭回执后可从“最近导入批次”找回，进入失败行修正；不必重新上传整份成功过的表。修正失败时保留当前输入，再次提交仍只处理相应失败行。

未记录重复数的旧批次会显示未知，不等于已经证明没有重复。没有失败行原记录的历史回执可能只可查看，界面会说明不能续做。

## 报错提供什么

提供发生时间、当前页面、可见提示和请求编号即可。不要把原始案情、人员信息、精确井位、账号密码或模型密钥贴到外部聊天。报错联系人由本单位管理员在启用时告知。
