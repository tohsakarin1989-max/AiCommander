## 本版增量

- 案件与设施选择复用授权全库查询，不再以当前页或地图首屏代替搜索范围；设施旧名与来源编号给出命中依据，公共地名明确是参考。
- 案件、设施、专题和材料保留选定对象、完整时间区间、成果引用及原列表返回位置；阅读动作不写入业务数据。
- 设施条件共用同一历史解析，区分业务有效时间、系统获知截止和迟到补充；区间内变化不再用单点代替。
- 案件概览直接显示少量已有历史参考；无匹配、部分就绪、索引故障与历史不可还原分别说明。
- 保留明确记录、空间邻近与候选解释的分层，保留旧页面、历史成果与原有角色权限。

操作说明见[找案找井指引](../find-cases-facilities.zh-CN.md)，具体证据见[v7.3 实施记录](../validation/2026-10-05-v73-implementation.md)。

## 接口和恢复

设施搜索保持原数组结构，仅增加可选的命中说明。历史档案继续接受旧点查询，新增完整区间和明确知识口径；非法或混合条件拒绝处理，不自动扩大范围。读取仍核验当前权限，冻结内容不代替授权。

本版本身没有新增数据库迁移、地图来源、路由引擎或语义模型依赖，使用 `v72m01` 结构；后续工作区已有更新的迁移，不可把它视为纯 v7.3 恢复包。恢复应用时使用与之相容的源码及备份，不要直接把旧应用接到未经核对的新库；保全新增案件、台账原件、字段采用记录和人工说明。
