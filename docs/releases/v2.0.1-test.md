# AiCommander v2.0.1-test 测试候选说明

## 定位

本版本是八周路线图第一周的测试服务器候选版本，不代表正式投产，也不代表
`v2.0.2-stable` 用户试用门槛已经通过。测试部署时 Agent Lab 必须保持关闭。

## 主要变化

- 加固生产认证、权限、健康检查、数据库迁移、升级前备份和回滚链路。
- 完善真实案件、事件、重点井和高关注井的大屏呈现与来源边界。
- 增加可独立关闭的 Agent Runtime、专用队列、事件、成果物、审批和重放记录。
- 增加案件数据质检、地图数据质检、双域融合研判和证据报告工具。
- 增加脱敏外发、工具白名单、审批幂等和源数据版本复核。
- 增加 Agent Lab 前端、隔离业务评测 Harness 和竞赛演示清单。
- 增加 GitHub 后端、前端与生产编排质量门禁。
- 增加可重复的隔离全栈部署演练、自动冒烟检查、运行版本校验和非破坏性备份恢复验证。

## 当前自动化验收

- 后端：221 项测试通过。
- 前端：18 个测试文件、78 项测试通过。
- Agent Runtime 专项覆盖率：84%。
- 隔离模拟评测：30 个案件、100 个地图资源，27/27 项检查通过。
- 全新数据库迁移、前端生产构建、Compose 和部署脚本静态检查通过。
- 本机隔离生产编排演练通过：PostgreSQL、Redis、后端、Celery、前端全部健康，
  Agent 保持关闭；迁移后备份成功恢复到临时数据库，共核验 39 张表，迁移版本为
  `c3a8d4f2b711`，临时容器、网络、数据卷和密钥均已清理。

可在具备 Docker 的开发机或测试服务器执行：

```bash
sh ./scripts/rehearse-v201-test.sh
```

该入口使用独立 Compose 项目、临时密钥、临时数据卷和回环端口，依次完成全栈部署、
Agent 关闭态核验、匿名权限检查、接口文档关闭检查、正式迁移后备份及临时数据库恢复，
完成后删除隔离容器和数据卷，保留不含密钥的验收证据目录。
