# AiCommander v4.2.0-stable 发布说明

状态：源码与本地验证已准备，远端合并及Release尚待完成；不代表现场投产。

## 本版交付

- 正常案件录入后自动生成道路距离比较，不增加一线用户必需操作。
- 统一受控机动车路网，封闭、无许可和未知门禁在构图前排除；车型参数来自画像或明确参考假设。
- 主路径、最多一项原生备选、绕行程度及沿路距离/时间预算道路，保留未知入口和数据缺口。
- 案件页面及Word/PDF使用同版留存成果，记录画像、地图、路网、条件、车型和计算版本。
- 独立道路队列、超时取消、当前权限复查、历史读取及模型/路由故障降级。
- 内网道路与文档组合运行包及预制镜像部署入口。

不认定实际行驶轨迹、具体居住地、嫌疑人或正式串并案；不自动创建执行任务。
预算线段不是完整区域覆盖，耗时不是准确ETA，无结果不证明现实不可达。
公共道路资料缺失、内部入口未核验、复杂限制不能可靠转换时保留缺口或拒绝构图，不猜测放行。

## 部署与回滚

APP_VERSION=4.2.0-stable，ALEMBIC_TARGET=head；迁移从4ef1b75a80e5增量到82d5f19ec429。
默认ENABLE_ROAD_ANALYSIS=false；准备同架构镜像及授权路网后开启，部署脚本加载道路组合及独立队列。
道路组合已包含报告运行库，不应再用文档override覆盖道路API镜像。
内网导入全部镜像后设置DEPLOY_IMAGE_MODE=prebuilt；参考[组合运行包](../../deploy/road-api/README.md)。

升级前备份数据库、地图和配置。回滚使用4.1兼容备份另库恢复，同时保护升级后新增原始数据；
禁止旧程序直接访问不兼容新库，禁止用删表降级代替恢复。
交付候选镜像保持其实际验证身份，目标架构、TLS、现场性能及模型配置在部署时确认。
不会以30天试用或固定业务评价数量阻塞源码Stable。
