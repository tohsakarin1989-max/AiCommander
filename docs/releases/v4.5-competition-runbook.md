# 4.x 六分钟展示与交付清单（收口执行版）

状态：五轮合成技术业务彩排已通过，现场六分钟人工展示未确认；不是v4.5 Stable发布声明。
沿用v3.6的数据边界，新增真实道路、统一成果、专题追问及空间覆盖内容。

## 场地与输入

- 使用独立数据库、地图目录、后台队列和测试账号，只导入合成案件与脱敏设施。
- 公共底图、字形、图标、地名索引与路网文件提前安装；记录地图、路网及镜像摘要。
- 不在现场下载地图、构建路网或修改生产通行条件。演示封路必须是隔离版本。
- 模型未配置时直说“确定性工具与降级演示”；不把历史轨迹或测试适配器称为现场模型推理。
- 本脚本是现场讲解顺序；后台技术彩排可以提前运行，不靠等待凑足六分钟。

## 六分钟主线

| 时间 | 入口与动作 | 必须看到的结果 |
| --- | --- | --- |
| 0:00—0:35 | `/dashboard`，选择同一辖区和周期 | 四项指标、主地图、趋势、最多三项重点；说明统计口径和截止时间 |
| 0:35—1:15 | `/cases`，录入或导入一条合成案件 | 保存先返回；后台自动生成画像，不让用户选井点或半径 |
| 1:15—2:05 | 案件详情展开统一成果 | 明述/否定/不确定分层，原文出处，支持依据、反向证据和缺项；展示画像与地图版本 |
| 2:05—3:05 | 同一成果的道路分析 | 直线接近不等于道路接近；展示实际沿路距离、车辆假设、版本及待核入口；封闭道路不能被使用 |
| 3:05—3:45 | `/assistant`，查询并追问 | 展示继承的范围、时间、不同工具轨迹及证据；未接模型时明确降级，不拿预录回答冒充实时调用 |
| 3:45—4:35 | `/situation`，周期比较及方案比较 | 案发时间和成果生成时间分开；真实点位/路网决定覆盖，重叠不重复计分；未知视场仅称名义覆盖 |
| 4:35—5:15 | 从同一成果导出Word/PDF | 页面与导出引用、候选、地图/道路版本一致；道路附件独立版本可回查 |
| 5:15—5:45 | `/showcase`或隔离环境故障场景 | 缺坐标不造候选，模型故障保留规则结果；分别标识真实停机和注入故障；回放不重新执行 |
| 5:45—6:00 | 总结 | 地图能计算、案件有证据、建议不自动执行；真实节时、命中率尚缺数据时写“持续收集中” |

`/showcase`现有三个内置场景不包含上述所有4.x页面。完整展示必须走完主线，
不能只重复点击三个场景按钮就宣布4.x完整展示通过。

## 五轮连续验证记录要求

每轮都完成主线，并保留实际浏览器结果、运行编号、导出摘要、版本与耗时。
只跑接口、只看截图或只构建成功，都不单独证明整轮完成。

| 轮次 | 本轮额外变化 | 预期行为 | 当前证据状态 |
| --- | --- | --- | --- |
| 1 | 正常输入 | 自动画像、道路、证据与导出贯通 | 技术彩排通过 |
| 2 | Worker中断恢复 | 案件可保存，恢复后画像不重复 | 技术彩排通过 |
| 3 | Redis中断恢复 | 不重启Worker，恢复后自动处理 | 技术彩排通过 |
| 4 | 路网目录版本变化 | 新版本后台刷新；旧成果保持版本边界 | 技术彩排通过；同图新目录，非新增拓扑 |
| 5 | 固定输入重放 | 两次真实队列重放记录一致 | 技术彩排通过 |

五轮统一包含缺坐标、模型不可用、覆盖方案移动及完整周期简报。
原始总报告：`output/v45-showcase-series-eod_7oq7/report.json`，具体目录见收口核对。
输入通过认证API写入合成案件，后续使用实际HTTPS浏览器，未模拟业务接口。
不将技术彩排计为人工输入耗时、完整否定语言理解、真实模型调用或现场六分钟讲解验收。

模型配置、现场讲解签字、目标服务器性能及真实业务效果仍属部署后确认，不重新设置固定样本量或30天试用门槛。
若智能问答未接真实模型，本轮只能证明降级和已有工具链；记录不得勾选“真实模型联通”。

## 最终交付包

1. 发布源码/版本、迁移说明和对应镜像摘要；普通修正不单独建Release。
2. 独立受控地图与路网包、许可与校验清单；不放入公开源码仓库。
3. 技术验证报告与上述五轮原始证据；注明模拟、原生计算和实际部署的区别。
4. 运行配置、故障降级、备份恢复与回退说明；密钥独立受控保存。
5. 固定输入评测及反馈口径；规则支持度不称为概率，缺标签不计为正确。
6. 真实效果待补清单；没有证据的改进比例不进入竞赛材料。
