# AiCommander v4.5.0-stable 发布准备

状态：4.5.0-stable发布分支，等待GitHub检查、合并和Release；不是现场投产证明。

## 本版交付

- 冻结案件特征、地图、道路、通行条件和算法输入，保留来源摘要，历史重放不读取后来修改的数据冒充原输入。
- 评测区分正例、负例、未标注、失败及空结果；人工标签保留修订理由、人员和版本。
- 按案件分组隔离训练与验证，展示基线、退步、样本不足和规则支持度；校准结果不自动投入生产。
- 道路版本发布后按原授权范围重新检查受影响成果，包含可能受新增连接影响、没有旧路径的案件。
- 无可信拓扑差异时使用整张适用图的保守范围，不宣称已实现最小网格级重算。
- 后台任务保留进度、取消、恢复与幂等控制；队列和模型不可用不阻断案件保存。
- 修复态势空态及折叠图表白屏，合并实际页面、覆盖方案、道路报告和故障降级展示证据。
