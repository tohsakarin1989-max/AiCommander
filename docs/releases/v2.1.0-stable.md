# AiCommander v2.1.0-stable 发布说明

发布日期：2026-09-04

## 版本定位

`v2.1.0-stable` 是“油盾·双域研判智能体”的首个稳定代码基线。它在不改变现有案件、
地图、报告和权限主流程的前提下，加入可独立关闭、可恢复、可审计的 Agent Runtime。

Agent Lab 和正式数据写入默认关闭。启用 Agent Lab 后仍默认使用内网规则引擎，不需要
模型 API 密钥，也不会向外部发送数据。默认生产依赖不安装 OpenAI Agents SDK；外部模型
仅保留为单独安全评审、另行构建实验镜像后的可选叙述适配器。

## 主要更新

- 新增 `agent_runs`、`agent_events`、`agent_artifacts`、`agent_approvals` 四类增量对象，
  保留任务状态、追加式轨迹、成果物、审批和重放依据。
- 新增独立 `agent_lab` 队列与可选 Agent Worker；Agent 故障不影响核心就绪状态。
- 提供案件数据质检、地图数据质检、案件—重点井双域分析和综合证据报告四类任务。
- 统一运行状态：`queued → planning → running → verifying → waiting_approval/completed`，
  并覆盖 `failed`、`cancelled`、`expired`、`degraded` 异常终态。
- 地图候选只允许清理未核验资源名称首尾空格，或使 Point 几何与现有经纬度一致；
  不允许 Agent 修改案件、经纬度和已核验资源。
- 管理员审批同时校验运行模式、写入开关、字段白名单、数据签名和幂等键。
- 新增 JSON 增量事件、SSE 事件流、取消、审批、管理员重放和 `/health/agents`。
- 前端新增受功能开关和角色权限保护的 Agent Lab，展示成果、证据、边界、审批和完整轨迹。
- 默认执行引擎调整为 `deterministic`；无模型、无密钥、无外网时可完成全部首期规则任务。
- OpenAI Agents SDK 移出默认生产依赖，单列为实验环境可选依赖。
- 收紧外发脱敏：除人员、电话、证件号、车牌、井名、地址和坐标外，同时删除作案方式原文、
  线索来源原文、精确案发时间、地图扩展属性及内部路径。

## 默认生产配置

```text
ENABLE_AGENT_LAB=false
AGENT_MODE=off
AGENT_MUTATIONS_ENABLED=false
AGENT_PROVIDER=deterministic
AGENT_MODEL=
AGENT_USE_EXTERNAL_MODEL=false
AGENT_EXTERNAL_DATA_POLICY=redacted_only
AGENT_SDK_TRACING_ENABLED=false
```

首次升级只创建 Agent 自有表，不启动 Agent Worker、不显示前端入口，也不改变核心服务行为。

## 数据库迁移

Alembic 当前目标版本：`c3a8d4f2b711`。

升级前必须备份 PostgreSQL，然后执行生产部署脚本或：

```bash
cd backend
alembic upgrade head
```

关闭 Agent Lab 不需要执行降级迁移；运行轨迹和审批记录应作为审计证据保留。

## 现场验收边界

源码和本机自动化不能替代以下现场证据：

- 目标服务器部署与网络策略确认；
- 指定用户使用真实脱敏样本开展影子运行；
- 人工处理时间与 Agent 辅助时间基线；
- Redis 中断、Worker 重启和断网等目标环境故障演练；
- 30 个脱敏案件、100 个地图资源的业务评测；
- 连续五次竞赛全流程演示和人工复核记录。

未完成上述现场事项时，可以将本版本用于受控测试部署，但不得表述为已完成正式业务验收。
