# AiCommander v2.8.0-stable 发布说明

发布日期：2026-09-08

## 发布定位

`v2.8.0-stable` 优先解决系统“能力很多，但日常人员不知道下一步先做什么”的可用性问题。新增今日研判
工作台，把案件数据治理、经验资产和版本化报告串为一条可完成的内业链路；Agent 继续作为可选旁路，
默认关闭，不影响核心系统就绪。

## 核心变化

- 新增角色感知的“今日研判工作台”，每起案件只显示一个明确下一步。
- 新增数据核验、经验生成/复核、报告生成/复核、当前闭环四段流程总览。
- 新增可恢复任务会话与全局“进行中”条，支持跨页继续、完成和放弃。
- 新增 30 日实用性度量：开始数、完成数、完成率、平均耗时和平均跨页。
- 管理员看全组聚合，分析员仅看本人，只读账号不采集会话。
- 路径记录自动删除查询参数并拒绝外部 URL；不采集案情、人员、井名或坐标。
- 修复旧版 `quality_issues.missing_required` 为字符串时案件自动化接口返回 500 的兼容问题。
- 新增迁移 `a7d9e1f2b304` 与专项验收脚本 `scripts/verify-workbench.sh`。

## 验证结果

- 后端：296 项测试通过。
- 前端：23 个测试文件、100 项测试通过。
- TypeScript 类型检查与 Vite 生产构建通过。
- Python 与前端生产依赖审计均未发现已知漏洞。
- SQLite、PostgreSQL 全新数据库均迁移到 `a7d9e1f2b304`，工作台表存在。
- 隔离生产编排、健康检查、内部端口限制、Agent 默认关闭、自动冒烟和备份恢复演练通过。
- 真实浏览器已验证登录、工作台三类任务分流、开始任务、跨页进行中提示，以及旧版质量字段兼容。

## 未替代的现场验收

本发布说明确认源码、本机测试和隔离容器演练结果，不代表目标服务器已部署或系统已正式投产。目标
服务器仍需完成数据库备份与迁移、网络与 HTTPS 检查、登录及核心业务验收；业务人员还需累计至少
20 次任务会话，才能评估真实节时、完成率和跨页减少情况。

## 升级与回滚

升级前执行数据库备份，部署时运行 `alembic upgrade head`。工作台任务会话与正式业务表隔离；关闭或
回滚工作台不会修改案件、井位、经验卡或报告。Agent Lab、外部模型与候选写入开关继续默认关闭。
