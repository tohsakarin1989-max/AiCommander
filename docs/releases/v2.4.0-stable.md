# AiCommander v2.4.0-stable 发布说明

发布日期：2026-09-07

## 版本定位

`v2.4.0-stable` 将案件—地图双域融合研判和综合证据报告开放为指定人员只读试用，并完整继承
v2.3 案件数据管家与 v2.2 地图数据管家。本版本仍以确定性内网规则为主，不要求 OpenAI 或其他
模型 API；Agent Lab、外部模型和正式数据写入默认全部关闭。

双域能力只处理用户本次明确选择的案件和有效地图资源。它输出案件—生产目标距离、所选范围内的
历史案件频次、作案手法标签、历史聚合热点、事实、推断、建议、信息缺口和证据索引；不读取范围外
数据补足结论，不预测犯罪、不自动确认串并案、不自动派发巡逻，也不生成正式数据写入操作。

## 主要更新

- 新增双域融合研判独立试用开关、指定人员名单、验收指标和管理员一键停用。
- `assist` 模式开放 `dual_domain_analysis` 与 `evidence_report`，两类任务均保持只读。
- 双域任务必须同时明确选择现有案件和状态有效的地图资源；默认单次最多 10 起案件、100 项资源。
- 空范围、单边范围、越限范围、不存在案件、失效资源和非名单用户均在入队前被拒绝。
- 空间计算只在所选资源内寻找最近生产目标；历史频次只使用所选案件，避免范围外数据进入证据链。
- 新增案件—地图空间关联和历史聚合热点成果，全部带案件与资源证据编号，并明确“待人工复核”。
- 综合证据报告在受控辅助模式下不产生候选审批；地图候选写入仍只属于独立地图数据管家。
- Agent 运行中心新增双域试用状态、分析案件数、关联资源数、证据覆盖率和独立一键停用入口。
- 运行详情新增空间关联和历史聚合热点呈现；管理员只能在仍具备双域名单权限时重放辅助任务。
- 保持外部模型可选、默认关闭；无模型密钥和无外网环境仍可完成全部双域分析。

## 新增接口

```text
GET  /api/agent-dual-domain/status
PUT  /api/agent-dual-domain/control
POST /api/agent-dual-domain/suspend
```

既有案件、地图、两个数据管家和 `/api/agent-runs` 接口保持兼容。双域控制接口只在 Agent Lab 已
启用时开放；调整试用范围和一键停用仅管理员可执行。

## 默认生产配置

```text
ENABLE_AGENT_LAB=false
AGENT_MODE=off
AGENT_MUTATIONS_ENABLED=false
AGENT_CASE_PILOT_MAX_CASES=30
AGENT_MAP_PILOT_MAX_ASSETS=100
AGENT_DUAL_DOMAIN_PILOT_MAX_CASES=10
AGENT_DUAL_DOMAIN_PILOT_MAX_ASSETS=100
AGENT_PROVIDER=deterministic
AGENT_MODEL=
AGENT_USE_EXTERNAL_MODEL=false
AGENT_EXTERNAL_DATA_POLICY=redacted_only
AGENT_SDK_TRACING_ENABLED=false
```

升级后不会自动开放任何 Agent 试用。隔离环境切换到 `assist` 后，仍需管理员单独指定双域试用人员
并主动开启。双域只读试用不要求开启 `AGENT_MUTATIONS_ENABLED`。

## 数据库与回退

本版本复用已有 `system_configs` 和四张 Agent 运行表，不新增数据库表或字段。双域试用开关和名单使用
系统配置表持久化；缺少配置时按关闭状态处理。Alembic 目标版本仍为 `c3a8d4f2b711`。

需要紧急回退时，可先在 Agent Lab 一键停用双域试用，再按需停用两个数据管家，并将全局开关恢复为
`off`、停止 Agent Worker。无需删除 Agent 表，也不得删除运行轨迹、成果物和审批证据。

## 现场验收边界

代码发布不等同于实际试用完成。以下材料仍需在目标环境留痕：

- 指定双域试用人员、试用时间段、所选案件与地图范围和复核责任人；
- 不少于 30 起脱敏案件、100 项地图资源的固定评测集和人工标准答案；
- 人工研判耗时、Agent 辅助耗时、有效关联数、无效关联率和建议采纳率；
- 范围外数据隔离、模型不可用、Redis 中断、Worker 重启、断网和一键停用演练；
- 案件自动写入 0 次、双域任务正式数据写入 0 次、未经审批地图写入 0 次、敏感字段外发 0 项；
- 连续五次竞赛演示记录。

未完成上述现场门槛时，本版本可作为前期测试部署和竞赛冻结代码，不得表述为已完成正式业务验收。
