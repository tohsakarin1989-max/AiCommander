## 本版功能

- 智能助手支持连续追问，自动继承明确的辖区、时间和筛选条件，变化时记录依据。
- 在七类只读工具中按问题选择：案件、地点、统计、周期比较、已有研判、历史道路成果及语义画像。
- 语义画像保留明述、否定、不确定、原文出处及本批去重分布；过期和损坏引用明确提示缺口。
- 道路成果展示留存距离、绕行与版本，不把历史条件视为当前可通行，不重新构图。
- 查询页面与Word/PDF共用冻结结果、证据、条件及轨迹，渲染结束再次检查权限。
- 普通新增案件不会使历史查询失效；范围移动、删除或账号权限变化触发保守失效。

最多8步、120秒，可取消。分页统计不是全库规律；规则支持度不是准确概率。
不修改原始案件，不生成身份、实际轨迹、正式串并案结论或执行任务。
