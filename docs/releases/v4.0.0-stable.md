# AiCommander v4.0.0-stable 发布说明

状态：2026-09-11（UTC+8）已正式发布[GitHub Release](https://github.com/tohsakarin1989-max/AiCommander/releases/tag/v4.0.0-stable)。
标签指向4df7fb10d400177eb9d2bc9a48b8e56aac0e99ca；PR #17及主分支检查34517572412全部通过。
这是源码Stable，不是现场投产证明。后续实现已进入v4.1分支，系列目标仍为v4.5。

## 本版能力

- 全授权案件分页检索、中文Excel工作表与字段模板、导入批次回执和失败行纠错，重复提交不重复建案。
- 日常大屏统一范围、周期和口径；四项指标、一张地图、趋势与最多三项关注重点，候选联动证据和案件详情。
- 大庆、齐齐哈尔公共矢量底图、字体、图标、样式和地名索引本地化，原生6—16级、显示到19级。
- 完整地图包分片续传、后台验包、登记发布与回滚；公共采集不携带生产数据。
- 五类只读智能查询、受控工具循环和隔离“展示”入口。外部模型不是核心业务依赖。

公共原始道路与限制关系保留，五组真实构图样例通过；本版不开放机动车业务路由。
道路通行约束归v4.2，语义画像和统一导出归v4.1，追问、覆盖比较及评测收口继续按路线图实施。

## 部署与恢复

APP_VERSION=4.0.0-stable，ALEMBIC_TARGET=head，迁移头f830b2152595。
由v3.6的a3e6b7c8d940增量经过b4f7c8d9e051、c508d9e0f162、d619e0f20373、e72af1041484。
升级前保存数据库、配置、密钥与地图文件；回滚另库恢复v3.6兼容备份，并保留升级后新增原始数据。
禁止旧程序直接连接新库或用破坏性降级替代恢复。

地图导入使用map-build可选服务与独立数据卷；智能查询使用agent-lab后台及可信内网模型配置。
默认ENABLE_AGENT_LAB=false、AGENT_MODE=off、ENABLE_SHOWCASE=false，自动地图发布范围默认空。
正式案件事实不被自动覆盖，推断不自动成为结论或执行任务。

地图包、生产资料、凭据和本地演练数据库不随源码上传GitHub。
目标服务器、真实台账、内部道路和业务评价持续补充，不重新设置30天试用或固定真实样本数量门槛。
