## 本版变化

- 同一份固定材料可以切换完整资料、案件资料摘要、设施资料单或周期情况材料；格式不适用时明确拒绝。页面和 Word/PDF 共用正文版本，不再次分析。
- 中文业务文件名包含日期与内容版本；导出校验格式及摘要，来源返回保留当前格式。
- 目录复用可重建元数据和明确来源引用，不为翻页构建每份完整文档或地图；当前权限始终在分页和数量前检查。正文检索语义保留，索引故障不丢历史材料。
- 三种专题预设沿用已有业务服务；首页按同案件/设施合并提示，保留全部可见来源。静音与暂停独立，“本次不再提示”只作用于明确的版本，打开页面不自动当作处理。
- 保留旧会议、历史报告和部署统计；移除旧页虚构百分比，注明直线、未校准和空间示意边界，接续到现有态势与材料。

材料格式均为通用整理，不冒充单位正式样表。办公软件改稿不会改写案件事实。

## 升级与恢复

迁移链为 `v72m01 → v74n01 → v74c01`，新增专题提示偏好/精确版本忽略，以及可重建材料元数据/引用两表，不复制业务正文。

后端和 `backend/document-renderer/render-docx.cjs` 必须一起交付；渲染器显式登记了三个新格式，沿用旧镜像不能当作新格式已部署。无新地图、路由、模型下载或运行依赖。

投影可安全重建，但静音和忽略记录是用户选择，非空时数据库迁移拒绝破坏性降级。回退使用相容应用与备份，保全升级后的原始案件、资料和人工记录，不直接把旧应用接入未经核对的新库。
