# v6.5.0-stable：统一材料与 6.x 业务收口

日期：2026-09-30。范围为 R10，并整合 v6.0—v6.4 尚未远端发布的源码工作。收口状态及最终发布证据见 [综合验证记录](../validation/2026-09-30-v65-implementation.md)；本文不代表目标服务器已经部署。

## 用户能直接使用什么

1. **同一个材料入口。** 案件、设施、专题、日周态势、助手、会议、经验及历史结论统一检索、阅读和导出。旧会议、旧案件成果及结论深链接保留来源定位，不要求重新分析或先做一次审批。
2. **同一版内容。** 页面、引用、地图和 Word/PDF 均绑定具体内容校验。地图缺失或版本失效时明确说明，不用当前地图替代历史依据。大专题采用明确标注的阅读概览，完整统计不截断；完整文档超出预算会拒绝，不生成悄悄省略内容的“完整版”。
3. **按需保存、按需判断。** 设施档案可显式冻结成材料；人工可对某一版本确认、保留参考、标注证据不足或附依据排除。重复请求不会重复保存，不自动改案件事实、办结状态或形成执行任务。
4. **历史业务保留但不重复生成。** 经验从已有冻结成果整理；会议使用固定输入。旧报告、人工决定、已确认经验和高级会议继续保留，普通用户不再进入结论工厂重复生成同案结论。
5. **退出无消费者的旧路径。** 旧结论生成、执行型巡逻/人员/重点部位管理、旧团伙运行入口及已淘汰的评分/410 空壳退出；原始案件人员、车辆、涉油数量、收缴、证据、奖励记录和历史表不删除。

v6.4 的受控查询、持续问题、完整统计续跑及变化提醒同时交付，详见 [v6.4 说明](v6.4.0-stable.md)。没有新增多智能体辩论、执法调度或自动事实认定。

## 接口与配置

- 统一目录：`GET /api/results`；统一阅读：`GET /api/results/{kind}/{id}`。
- 同版出口：`document.docx`、`document.pdf`、`map`、`map.png`。
- 设施冻结：`POST /api/results/facilities/{asset_id}`；可选判断：`POST /api/results/{kind}/{id}/judgments`。两个写接口均要求幂等键并复查权限/内容版本。
- `ENABLE_LEGACY_OPERATIONS_MODULES=true` 已在全部环境禁止；历史配置须改为 `false`。旧表保留，不能用此开关恢复已移除执行模块。
- 默认不接通任何真实模型。开查询不等于开 Agent Lab，也不等于允许案情外发。材料及专题后台不依赖模型。
- 地图包、字体包、路由和模型文件沿用既有受控内网交付；公开源码不包含业务库、生产坐标或内部地图包。

## 升级步骤

1. 备份当前相容应用、数据库、原件、地图和生产资料；在隔离副本演练，不能直接清空测试库。
2. 数据库仍要求 PostgreSQL/PostGIS/pgvector。停止旧写入及消费者，按现有部署手册升级；6.x 迁移链为 `v60c01 → v61s01 → v62i01 → v62f01 → v63h01 → v64t01 → v65r01`，最终单一头为 `v65r01`（更早前驱由 Alembic 决定）。
3. 本版 `v65r01` 只新增 `facility_materials`、`result_judgments`、`meeting_frozen_inputs`；原案件、设施、会议、经验和人工历史语义不改变。
4. 后端、前端、普通 Worker、查询 Worker 与 Beat 同步更新。核对案件保存、画像/索引后台处理、专题续跑、统一材料、权限、同版地图及 Word/PDF。
5. 本地验证和目标服务器验证分别记录；没有真实模型时保留未启用状态，不把合成测试计入真实模型效果。

## 回退与恢复

新表非空时 `v65r01` 降级主动拒绝，以保护已保存材料和人工意见；`v64t01` 也禁止自动删除用户条件。不要删新记录来绕过保护。

回退应完整保存升级后的数据库和原件，在独立数据库恢复与旧应用兼容的备份，经核对后切换；升级之后的新案件、证据、生产资料、人工决定须另行保全和受控迁回。只切换旧程序不等于数据库恢复。隔离 PostgreSQL 的独立备份恢复已验证，不冒充现场恢复。

## 验证与剩余边界

功能、浏览器、性能、迁移、并发与实际 GitHub 发布状态集中记录在 [综合验证](../validation/2026-09-30-v65-implementation.md)，材料专项见 [R10 验证](../validation/2026-09-30-v65-materials.md)。相关批次有重叠，不能把通过数相加当作独立总量。

真实内网模型、目标服务器负载和正式业务有效性仍待部署后核对；本次不重新下载两市地图、编译路由或修改现用业务数据库。6.x 源码收口不等于正式投产。
