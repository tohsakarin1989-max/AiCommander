## 本版交付

- 案件后台自动生成带原文位置及版本的语义画像，区分明确、否定、矛盾和缺失信息。
- 案件详情、分析工作台、报告中心使用统一冻结成果，支持带离线地图的Word/PDF。
- 内部道路保留完整线形、稳定编号、来源版本及核验历史；入口连接证据绑定道路版本。
- 共享导出预算、权限复查、取消等待及失败提示；公共地图更新不会覆盖内部已核验资料。

正常录入无需手动选择研判资源；原始案情不被自动改写。复杂文本保留信息缺口，
内部道路的连接证据不等于通行许可。本版不开放机动车路由，继续在4.2实施。
