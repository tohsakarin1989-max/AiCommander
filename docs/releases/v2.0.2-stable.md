# AiCommander v2.0.2-stable 发布说明

> 此版本已由 `v2.0.3-stable` 替代。后者收紧会话令牌的规范 Base64URL 校验，并消除
> 安全回归测试中的随机性；新部署请使用 `v2.0.3-stable`。

## 定位

本版本是面向前期测试部署的稳定代码基线。它已通过仓库全量回归、生产构建、配置检查、
全新数据库迁移、隔离五服务部署、自动冒烟和 PostgreSQL 备份恢复演练。Agent Lab 继续
默认关闭，不参与核心系统就绪判定。

`stable` 表示当前代码与部署链路达到受控测试部署门槛，不等同于目标单位正式投产验收。
目标服务器网络与 HTTPS、现场备份证据、指定用户试用和业务效率基线仍须在部署后记录。

## 纳入的稳定能力

- 案件录入、导入、保存前预检、批量复核、待办分流和报告主流程。
- 真实案件、事件、重点井与高关注井地图展示，以及链条和时空研判能力。
- 管理员、分析员、只读账号三级权限，会话保护、登录锁定和写操作审计。
- PostgreSQL 16、Redis 7、后端、Celery、前端五服务生产编排。
- 数据库增量迁移、升级前备份、非破坏性恢复核验、健康检查和回滚手册。
- 独立 Agent Runtime、轨迹、成果物和审批底座；发布态全部关闭，不触碰正式业务数据。

## 自动化与隔离验收基线

- 后端：221 项测试通过。
- 前端：18 个测试文件、78 项测试通过；TypeScript 类型检查和生产构建通过。
- Agent Runtime 专项覆盖率：84%。
- 隔离模拟评测：30 个案件、100 个地图资源，27/27 项检查通过。
- 本机隔离生产编排演练：五个核心服务健康，Agent Worker 未启动，只有前端绑定回环端口。
- PostgreSQL：全新迁移完成，备份恢复至临时数据库并核验 39 张表，迁移版本
  `c3a8d4f2b711`。

发布前可重复执行：

```bash
sh ./scripts/rehearse-release.sh
```

演练使用独立 Compose 项目、临时密钥、临时数据卷和回环端口；结束后清理临时资源，
只保留不含密钥和业务数据的验证清单。

## 目标服务器部署验收

首次部署必须保持：

```dotenv
ENABLE_AGENT_LAB=false
AGENT_MODE=off
AGENT_MUTATIONS_ENABLED=false
```

并补齐以下现场证据：

1. 目标服务器域名、HTTPS、端口暴露和单位网络策略检查。
2. PostgreSQL 备份、校验和非破坏性恢复演练记录。
3. 案件录入/导入、预检、批量复核、地图、报告、权限和 WebSocket 业务复验。
4. 指定用户试用时长、人工处理耗时、错误类型、问题率和操作步骤基线。

上述现场证据是进入 `v2.1-agent-lab` 影子验证及后续辅助模式的前置输入，不得用自动化
测试结果代替。
