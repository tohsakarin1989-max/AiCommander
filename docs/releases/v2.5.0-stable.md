# AiCommander v2.5.0-stable 发布说明

发布日期：2026-09-07

## 版本定位

`v2.5.0-stable` 在 v2.4 双域融合研判基础上补齐统一 Agent 运行中心、多模型适配和成本/性能监控。
本版本不改变案件数据管家、地图数据管家和双域研判的人工复核边界，不把模型变成核心依赖：默认仍由
内网规则引擎完成全部事实计算，不需要 OpenAI 或其他模型 API，也不会向外部发送数据。

经内网安全评审后，部署人员可选择 OpenAI Agents 适配器，或通过系统已有模型注册表接入
OpenAI/OpenAI-compatible/Azure OpenAI/Anthropic。模型只负责整理已经脱敏的确定性结果；提供方不可用、
超时或响应非法时，任务保留规则成果并标记为降级完成。

## 主要更新

- 新增近 1—90 天统一运行概览，默认展示 30 天任务量、完成率、降级/失败、平均耗时与 P95 耗时。
- 按提供方汇总任务量、模型请求、Token、平均模型耗时和估算成本。
- 每次模型调用保存提供方、模型名、成功/失败、耗时、输入/输出 Token、估算成本和错误类型。
- 运行详情增加总耗时、工具耗时、模型耗时、Token 和估算成本，便于业务试用与竞赛使用同一套轨迹。
- 复用现有模型注册表，部署时通过模型 ID 选择已启用模型；不向普通用户开放逐任务任意切换。
- 模型目录 API 只返回安全元数据，不返回 API Key、网关地址或模型完整配置。
- OpenAI Agents SDK 继续保持可选依赖；默认生产镜像和默认配置均不要求 OpenAI API。
- 模型故障会记录失败计量并进入确定性降级，不影响案件、地图、报告和权限等核心业务。

## 新增接口

```text
GET /api/agent-runs/overview?days=30
```

管理员和分析员可读取运行概览；只读账号仍不能访问 Agent Lab。已有运行详情响应新增 `performance`，
详情模式新增 `usage_records`。原有创建、取消、审批、重放和事件接口保持兼容。

## 默认生产配置

```text
ENABLE_AGENT_LAB=false
AGENT_MODE=off
AGENT_MUTATIONS_ENABLED=false
AGENT_EXTERNAL_DATA_POLICY=redacted_only
AGENT_PROVIDER=deterministic
AGENT_MODEL=
AGENT_MODEL_ID=
AGENT_MODEL_INPUT_COST_PER_MILLION_USD=0
AGENT_MODEL_OUTPUT_COST_PER_MILLION_USD=0
AGENT_USE_EXTERNAL_MODEL=false
AGENT_SDK_TRACING_ENABLED=false
```

成本单价为每百万 Token 的美元价格。没有配置单价时仍记录调用量与耗时，估算成本为零；估算值仅用于
运行管理，不作为供应商账单。生产预检会拒绝非法提供方、外部模型与 `local_only` 的冲突，以及缺少
模型名或模型 ID 的启用配置。

## 数据库与回退

新增迁移 `e4b5c6d7a812` 和表 `agent_usage_records`。该表只追加模型运行计量，不保存提示词、响应正文、
密钥、网关地址、案件内容、井名或坐标。升级执行：

```bash
cd backend
alembic upgrade head
```

紧急情况下先关闭 Agent Lab 和外部模型、停止 Agent Worker，核心业务可继续运行。不要删除运行轨迹或
计量记录。若整体回退数据库，必须先完成备份并确认没有需要保留的 v2.5 计量证据，再按运维手册操作。

## 现场验收边界

代码发布不等同于目标服务器或真实模型已经完成验收。以下事项仍需现场留痕：

- 实际部署环境中 Agent 默认关闭，核心业务回归率 100%；
- 真实内网/外部模型提供方的连通性、超时、非法响应和断网降级；
- 模型单价口径、Token 统计与真实账单抽样核对；
- 不少于 30 起脱敏案件和 100 项地图资源的业务评测；
- 未经审批写入 0 次、案件和双域正式数据写入 0 次、敏感字段外发 0 项；
- 指定业务人员对有效关联、耗时下降和报告可用性的复核；
- 连续五次竞赛演示和故障注入记录。

未完成这些现场门槛时，本版本可作为前期测试部署与竞赛冻结代码，不得表述为已正式投产或已完成
真实模型验收。
