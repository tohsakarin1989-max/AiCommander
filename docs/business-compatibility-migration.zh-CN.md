# 旧业务入口适配说明

> 2026-09-30 v6.5 覆盖：下表中的无消费者 `410` 壳和旧结论生成接口已退出，历史旧结论通过 `/reports?kind=conclusion&resultId=...` 读取；旧 `/conclusions` 页面链接兼容跳转。统一材料 API 为 `/api/results`。旧表及人工记录保留，执行模块不能再通过开关开启。当前新增迁移和回退保护见 [v6.5 发布说明](releases/v6.5.0-stable.md)，下文的“无迁移/直接恢复旧接口”仅适用于原 v5.4 工作包。

日期：2026-09-25。适用于 v5.4 工作区的业务精简改动；不是新版本发布或部署记录。

## 1. 已停止的新计算入口

以下接口仍保留地址和身份认证，但返回 `410 Gone`，响应给出替代入口。不会自动转发旧请求、继承不明确的权限范围，也不会执行数据库写入或调用模型。

| 旧接口 | 替代业务入口 |
|---|---|
| `POST /api/assistant/chat` | `/assistant`，通过 `POST /api/intelligent-queries` 创建受控任务；追问使用 `parent_query_id` |
| `POST /api/agents/run` | 同上；不再创建旧单轮任务 |
| `GET /api/case-intelligence/area-profiles` | `/area-analysis`，区域条件对照，不返回替代风险分 |
| `POST /api/events/area/analyze` | `/area-analysis`、`/situation` |
| `GET /api/events/area/risk-ranking`、`GET /api/events/area/hotspots` | 同上；停止旧事件数量和时间加权风险排名 |
| `POST /api/events/areas/{area_name}/refresh` | 同上；不再覆写历史区域评分 |
| `POST /api/deployment/smart-analysis` | `/situation` 查看已有周期成果；不再同步串联旧评分模块 |

区域条件接口为 `/api/facility-analysis/region`，周期简报为 `/api/situation/briefs/latest`。这些接口与旧评分含义不同，调用方必须调整展示，不能将缺失旧分值补为 0。

旧 `GET /api/agents/tasks` 继续读取已有记录，且不依赖 Agent 执行开关。旧任务没有完整的来源范围记录，因此仅向全域管理员开放，不按猜测的案件列表向普通用户放行。独立事件、人工关系、历史区域档案、会议报告及人工确认记录均保留；未删除业务表或历史数据。

## 2. 历史检索兼容

- 高级相似案件和经验推荐复用统一授权历史检索，不再截取最近 500 起案件。
- `days` 仍限制所选时间窗；“全库”指完整授权范围内、符合查询条件的来源，不等于忽略时间条件。
- 内部案例召回最多 200 条供经验推荐使用，公开统一搜索与经验搜索仍最多返回 20 条。
- 返回 `state`、`coverage`、来源版本、共同条件和不同条件。预算内未完成时明确显示部分结果；服务故障不等同于无匹配。
- 旧 `similarity_score` 仅为统一检索支持度的兼容换算；不再返回虚构的旧时间、距离分项。界面改称“检索支持度（非概率）”。
- 否定、待核、推断与明确陈述分别保留。草稿、确认及归档经验的状态不混用。

无权访问或来源失效返回 404；服务读取失败返回 503，均不泄露内部异常详情。

## 3. 报告快照只整理已有成果

`POST /api/knowledge/cases/{case_id}/report-snapshots` 现在读取已有、未过期且可访问的冻结案件成果，并附上人工选中的已确认经验引用。不再同步刷新案件质量或调用旧即时报告分析。

- 没有冻结成果：409，提示等待正常后台生成。
- 成果过期：409，提示等待后台更新，不使用过时内容冒充当前结果。
- 旧 `days`、`limit` 参数继续接收并记录，但不改变冻结成果范围、不触发重算；报告以成果记录的范围和版本为准。
- 相同成果与相同经验版本重复保存保持幂等。
- 历史报告内容不被更新覆盖；读取时重新检查当前来源权限。失去权限的资产不显示内容，其他仍可访问资产继续展示，列表 `total` 仅表示本次可交付条目数。
- 经验确认、报告确认及复用决定仍为显式人工操作，不自动改写正式案件。

缺少后台成果时，应检查案件派生处理状态。普通用户无需为旧报告手动选择数据重跑；管理员保留现有补齐和失败重试能力。

## 4. 经验预览语义适配（2026-09-27）

- 自动标签仅从原始字段和有出处的结构值提取，不读取 `features` 中的历史模型结果、经验总结或人工标签文本。人工增删标签仍为独立层。
- 肯定标签与 `observations` 中的否定、待核、肯否并存表述分开，附原文或 JSON 路径引用；复杂作用域、未知结构或提取不完整时保留未知。
- 未找到村屯不代表偏远，未找到技防不代表防护不足，靠近道路不代表道路可达。这些缺口不会被计入防护短板。
- 新预览始终待确认；新经验版本写入独立知识资产，不覆盖旧案件 JSON。兼容批量生成保留已确认/归档旧卡；需要新内容时通过“保存经验卡版本”生成独立草稿。
- 共享语义规则版本为 `local-events-5.1.0-2`，旧标签适配规则为 `source-polarity-2026-09-27-1`。画像与历史索引的既有版本检查生效，不自动将旧派生内容标为本轮修复后的结果。本次未批量重建业务库，也未改写历史确认卡和报告。
- 事件页旧区域高等级档案明确标为历史存档，不代表当前风险；读取失败不以零值或旧缓存伪装成功。

## 5. 配置与恢复

默认关闭旧扩展运行模块，Agent 关闭时停止空查询排程；在途任务和历史记录不自动清除。开关生效、Beat 重启、开发环境兼容启用方法见 [运行开关说明](runtime-feature-switches.zh-CN.md)。

本次没有数据库结构迁移，回退不需要清空数据。若恢复旧接口，仅恢复本轮源码与配置并重新部署兼容版本，保留已产生的报告快照和原始资料；不要整库还原或覆盖其他未提交改动。新生成报告采用冻结成果契约，较老程序未验证的读取表现不能视为兼容保证。
