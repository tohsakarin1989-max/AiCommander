# 项目文档目录

本目录统一存放非运行时代码资料，避免根目录混放原型、申报材料和路线图。

- `AI_COMMANDER_UPGRADE_TODO.md`：系统升级路线图与待办。
- `LLM_INTEGRATION_MAP.md`：大模型能力接入位置和功能边界。
- `server-deployment-runbook.zh-CN.md`：v2.4 服务器安装、迁移、HTTPS、备份恢复和回滚手册。
- `agent-lab-runbook.zh-CN.md`：Agent Lab 模式、两个数据管家与双域研判试用、权限、脱敏、故障降级和验收手册。
- `competition-demo-checklist.zh-CN.md`：竞赛冻结、连续演示和真实成效记录清单。
- `releases/`：各稳定版本的发布说明与验证边界。
- `design-reference/`：静态页面原型、视觉参考，不参与构建。
- `submission-materials/`：本地私有材料目录，已在 `.gitignore` 中排除，不上传公开仓库。
- `superpowers/`：历史设计规格和重构方案草稿。
