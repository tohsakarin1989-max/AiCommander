# 9.x 数据权威、来源与输出契约

本表登记当前代码的主写入位置，不将兼容字段、派生画像或模型输出另立为事实来源。复用既有 6.x—8.x 事实契约的部分不是本轮新增功能。

| 业务含义 | 权威写入与读取 | 兼容及保护 |
| --- | --- | --- |
| 发现、案发、录入时间 | `CaseService` 经 `case_intake_contract.normalize_intake` 校验；时间统一存储，保留原时区、原文及精度 | `case_time_window` / `CaseSearchService` 接受明确时间轴；未声明口径的旧链接保留旧约定；未知不以录入替代 |
| 地点角色与空间对象 | `CaseLocation`；通过 `CaseService` 成组校验地点 ID、角色、精度、几何 | 只有唯一精确案发点可投影到主坐标；发现地和模糊区域不能冒充案发端点；旧地点原词保留 |
| 车辆、人员 | `CaseVehicle` / `CasePerson`，在案件事务内同步 | 旧 JSON 输入只作为兼容输入保全；不以模型输出重新覆盖结构化人员车辆；明细 ID 必须属于当前案件 |
| 数量、单位与环节 | `OilMeasurement` 保存查获、移交、追回等不同环节；旧单值保留原有来源 | 不跨单位相加，不因吨/升文本接近而换算，不把查获量自动等于移交量 |
| 本单位处置、已知公安反馈 | 案件显式输入与 `feedback_known_fields` | 未获反馈不是否；历史默认布尔值保留旧语义提示；本单位移交不代表公安办结 |
| 案件来源更新 | `CaseImportSourceRecord` 的厂区、来源键、外部记录键唯一身份；源行版本与最后实际采用值 | 相同键不重复建案；只移动此次采用字段的保护基线；人工变化、空白清值、键复用进入冲突，不把表中缺席当删除 |
| 设施及生产资料 | `map_feature_adoption` / 地图采用计划，共用稳定来源身份和字段采用服务 | 手工、旧 GeoJSON/Excel、受管台账共用版本；同名不同编号不合并；手工编辑保存人工观察来源 |
| 原件与修订 | `EvidenceObject`、`SourceReference`、`CaseRevision`、设施来源 claim / version | 剪贴板原文标为人工粘贴，不声称已取得原 Excel；文件原件和行号与采用结果关联 |
| 画像与答案 | 独立派生画像、`QuestionSpec`、`TimeScope`、`AnswerSnapshot` | 模型及规则提取不能直接成为正式事实；任务成功与问题已回答分别记录 |

## 词表与未知值

案件既有单位、手法与画像字典继续由相应输入/派生服务管理。本轮新增的小型设施词表保留原词、标准码、精确别名依据及 `facility-vocabulary-9.2-1` 版本，覆盖设施类别、油品、产量单位、含水率单位、周期及生产状态。未命中保留原词，组织单位名称不做相似文本自动合并。词表归一不是事实核验，不改变数值或计量环节。

新设施输入未评级时风险等级为空、置信度为空；来源权威度不等于事实 100% 正确。历史人工值不追溯清空。未知投影和未经核验的本地坐标路径保持隔离。

## 来源、授权与历史答案

三类明确业务问题新增可信冻结回执、完整性核对及当前权限检查。正常来源更正后，足够完整的旧快照可按“截至当时”读取；撤权、源记录删除/撤回、缺乏可信冻结或内容不一致不会因历史查看而绕过限制。

复杂道路/专题旧成果没有充分冻结依赖时，继续采用严格失效策略；不是将所有旧成果一律解锁。复用覆盖三类问题及可完整绑定依赖的规则查询；依赖规模或类型不能可靠校验时重新创建任务，并明确原因，不宣称精准增量。

## 输出与维护权限

- CSV/XLSX 读取当前全部授权筛选结果，而不是前端一页；超过 50000 条明确要求缩小范围，不静默截断。
- 输出字段为白名单，表头防公式注入；原编号为文本，未知为空，单位同行保留。下载再次鉴权。
- 输出配置不可变、带版本、按厂区授权；自定义配置不是单位正式批准样表。
- 材料组合读取既有冻结材料，必要证据、时间版本、适用边界和反向依据不能隐藏；未识别的历史章节保守保留。
- 地图资料维护要求当前厂区 `manage`；普通 `write` 不自动获得维护权。原件下载、用户配置、道路权限和全域地图发布保持各自权限。
- 显示地图资源、生产资料准备度、道路计算条件分别展示；发布记录不等于资源校验通过，队列在线不等于 Worker 消费正常。

## 本轮未宣称的效果

没有配置或验收真实内网模型；没有取得单位官方表样；没有以合成样本计算员工节时比例；没有完成目标服务器或正式业务验收。源码发布保持这些状态可见，不以“Stable”消除现场条件。
