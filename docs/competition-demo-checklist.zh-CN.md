# “油盾·双域研判智能体”v3.6 竞赛冻结与六分钟演示清单

更新日期：2026-09-10

本清单按 v3.6 的实际工作流重写。普通用户不再选择案件、井点、半径或手工启动 Agent；系统从正常案件录入开始，自动生成案件画像、双域候选和部署参考。

门禁分为两层：

- 源码 Stable 技术门禁：可在受控隔离环境自动重复验证，必须通过后才能冻结版本。
- 发布后现场确认：目标服务器、单位网络、现场讲解节奏和业务人员评价，不再阻塞源码 Stable，但未完成前不得表述为正式投产或已获得真实业务成效。

## 一、源码 Stable 技术门禁

- [x] Agent 关闭后，后端、前端、类型检查和生产构建全部通过。
- [x] 案件保存不等待后台分析；Outbox Worker 暂停时案件仍能保存，恢复后可继续处理。
- [x] 自动能力写入画像、候选和部署参考，正式案件字段变化 0 次。
- [x] 自动创建巡逻、调查、抓捕或处置任务 0 次。
- [x] 每案候选不超过 3 项，证据引用覆盖率 100%。
- [x] 每项候选包含反向证据或信息缺口，覆盖率 100%。
- [x] 每期部署参考不超过 3 项，并明确只供人工判断。
- [x] 模型不可用时真实尝试 1 次并记录超时，成功外部模型调用 0 次，随后确定性降级链路完成。
- [x] Outbox Worker 暂停恢复、Worker 领取后重启、任务幂等重放均通过。
- [x] 在最终隔离生产编排中真实停止并恢复 Redis，核心接口保持 200/degraded，恢复后回到 ready。
- [x] 受控公共离线地图包通过逐瓦片真实解码，浏览器断网运行且公网地图请求为 0。
- [x] `v3.0.0-stable` 正式标签重建、核心健康检查、备份和恢复演练通过。
- [x] 使用受控公共离线地图包连续完成 5 次自动业务链路彩排。

五轮彩排不是单元测试替代物：每轮都在一次性数据库中使用真实离线地图包，实际执行案件保存、事务 Outbox、案件画像、双域研判、证据生成和部署参考服务；结束后自动删除全部脱敏演示数据。

## 二、v3.6 六分钟演示节奏

| 时间 | 操作 | 必须展示的证据 |
|---|---|---|
| 0:00–0:35 | 说明真实痛点、数据边界和离线底图 | 地图来源、版本、脱敏说明、原始案件和精确生产数据不出域 |
| 0:35–1:15 | 正常录入一条脱敏案件 | 用户新增必需操作为 0；案件先保存，后台任务不阻塞录入 |
| 1:15–2:00 | 查看案件治理结果 | 标准画像、质量评分、最多三项关键缺失、规则和字典版本 |
| 2:00–3:15 | 查看自动双域候选 | 来源、囤储、活动区或路径候选；支持证据、反向证据、信息缺口和地图版本 |
| 3:15–4:15 | 查看地图上的候选区域 | 真正离线地图、生产图层快照、区域级表达，不输出具体门牌或确定性居住地 |
| 4:15–5:05 | 查看态势部署参谋 | 最多三项部署参考、资源假设、有效期、证据和“不自动执行”边界 |
| 5:05–5:40 | 展示故障降级 | 模型不可用、Outbox Worker 恢复或 Worker 重启后，正式案件不变、任务可恢复 |
| 5:40–6:00 | 总结实效 | 只展示已经实测的指标；暂无真实业务样本时明确写“持续收集中” |
