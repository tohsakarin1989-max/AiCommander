## 一、冻结前硬门槛

- [ ] Agent 关闭后，核心业务全量回归通过率 100%。
- [ ] 未经审批写入正式案件或地图数据 0 次。
- [ ] 已批准操作重复提交造成重复写入 0 次。
- [ ] 有效成果物证据引用覆盖率 100%。
- [ ] 含姓名、电话、证件号、车牌、井名、地址、案情、案件编号和精确坐标的脱敏样本泄漏 0 项。
- [ ] 模型、Redis 和 Agent Worker 不可用时，核心系统仍可使用。
- [ ] 坐标异常均显示“待核验”，没有表述为已确认事实。
- [ ] 30 个脱敏案件、100 个地图资源的业务评测 Harness 通过。
- [ ] 连续五次全流程演示全部成功。

## 二、六分钟演示节奏

| 时间 | 操作 | 必须展示的证据 |
|---|---|---|
| 0:00–0:35 | 说明真实痛点和双域数据 | 人工耗时基线、数据口径、脱敏说明 |
| 0:35–1:15 | 导入脱敏案件和重点井数据 | 数据量、版本号、无真实身份信息 |
| 1:15–2:10 | 发起案件与地图数据质检 | `queued/planning/running` 轨迹、工具白名单 |
| 2:10–2:55 | 查看问题和候选修正 | 每条问题的案件/资源临时证据编号 |
| 2:55–3:35 | 管理员审批并重复提交 | 无审批不写入、重复审批不重复写入 |
| 3:35–4:35 | 重新进行双域融合研判 | 距离、时间、历史频次、数据缺口及“非犯罪预测”边界 |
| 4:35–5:20 | 生成研判报告和热点展示 | 事实/推断/建议/缺口分栏、100%证据引用 |
| 5:20–5:50 | 注入模型故障 | 规则结果保留、状态 `degraded`、核心业务正常 |
| 5:50–6:00 | 总结实效 | 时间下降、问题发现、采纳率三项真实指标 |
