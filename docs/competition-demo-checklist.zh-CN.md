# “油盾·双域研判智能体”竞赛冻结与六分钟演示清单

> 本清单用于记录真实演示和试用证据。未实际执行的项目保持空白或标记“待完成”，不得用单元测试数据替代。

## 一、冻结前硬门槛

- [ ] Agent 关闭后，核心业务全量回归通过率 100%。
- [ ] 未经审批写入正式案件或地图数据 0 次。
- [ ] 已批准操作重复提交造成重复写入 0 次。
- [ ] 有效成果物证据引用覆盖率 100%。
- [ ] 含姓名、电话、证件号、车牌、井名、地址、案情、案件编号和精确坐标的脱敏样本泄漏 0 项。
- [ ] 模型、Redis 和 Agent Worker 不可用时，核心系统仍可使用。
- [ ] 坐标异常均显示“待核验”，没有表述为已确认事实。
- [ ] 30 个脱敏案件、100 个地图资源的业务评测 Harness 通过。
- [ ] 连续五次全流程演示全部成功。
- [ ] 非试用名单账号无法发起受控辅助任务；双域试用账号必须同时明确选择案件和有效地图资源。
- [ ] 双域输出仅复盘所选范围内的历史时空条件，不包含范围外案件或资源，不形成犯罪预测和自动串并案结论。
- [ ] 一键停用后活动任务取消、待审批候选失效，核心案件和地图功能继续可用。
- [ ] 统一运行中心可展示任务完成率、P95 耗时、模型调用、Token、估算成本与降级次数，且页面/API 不含密钥和模型网关地址。
- [ ] 如启用可选模型，真实账单与系统估算成本已抽样核对并记录单价口径；未启用模型时明确展示内网规则模式和零模型调用。
- [ ] 只有人工确认的经验卡进入历史案例推荐；未确认或已归档经验进入报告 0 次。
- [ ] 历史经验的采纳、不适用和报告引用均可回溯，复用过程不会修改案件或复制旧案结论。

## 二、六分钟演示节奏

| 时间 | 操作 | 必须展示的证据 |
|---|---|---|
| 0:00–0:35 | 说明真实痛点和双域数据 | 人工耗时基线、数据口径、脱敏说明 |
| 0:35–1:15 | 导入脱敏案件和重点井数据 | 数据量、版本号、无真实身份信息 |
| 1:15–2:10 | 指定试用人员并发起地图数据质检 | 真实地图资源选择、`queued/planning/running` 轨迹、工具白名单 |
| 2:10–2:55 | 查看问题和候选修正 | 每条问题的案件/资源临时证据编号 |
| 2:55–3:35 | 管理员审批并重复提交 | 无审批不写入、重复审批不重复写入 |
| 3:35–4:35 | 重新进行双域融合研判 | 距离、时间、历史频次、数据缺口及“非犯罪预测”边界 |
| 4:35–5:20 | 复用已确认经验并生成研判报告 | 相似条件、差异提示、人工选择、事实/推断/建议/缺口分栏、100%证据引用 |
| 5:20–5:50 | 展示统一运行中心并说明模型故障降级 | 耗时、Token、估算成本、降级次数、规则结果保留和核心业务正常 |
| 5:50–6:00 | 总结实效 | 时间下降、问题发现、采纳率三项真实指标 |
