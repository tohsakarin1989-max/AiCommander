# 生产台账整理简明指引

适用范围：7.x 台账整理工作包。功能验证与发布状态以[实施索引](validation/2026-10-01-v7x-implementation.md)为准；本文不表示已在现场部署。

## 第一次：为这类台账保存模板

地图管理员进入地图资料管理，选择已登记的来源。不要把公共地名资料和内部生产主台账放在同一来源下。

1. 下载中文示例了解字段，或直接选择已有 Excel/CSV 读取表头。
2. 核对工作表、表头行和原列映射。选择实际坐标系、经纬轴顺序及单位，不凭数字外观猜坐标系。
3. 有生产数据时，同时说明含水率口径、产量单位和周期、资料有效期。资料不知道就保留未知，不填零代替。
4. 保存模板，再用同一文件预览。此时尚未写入设施。
5. 核对新增、更新、未变、身份待对应、冲突和失败。展开变更行可看旧值与新值，再选择“按预览写入合格记录”。

没有可靠编号的行不会因为同名就并入其他设施。不同编号的同名设施各自保留。来源、结构、坐标或单位不明确时，先处理提示，不盲目重试。

## 以后：选原模板，只处理变化

选择同一来源及保存的模板，再选新台账。系统复用映射并列出变化；表头或单位变化会提示，需要核对并保存新模板。新模板不改写旧批次。

- 正常新行按规则进入资料层；冲突和坏行留下回执。
- 同值行保留接收依据，但不重复增加设施业务版本。
- 提交超时表示结果未确认，不等于未导入。使用“用原文件与凭证核对并重试”，或打开最近批次查看，不换文件另建一次。
- 台账写入不是离线底图发布，两者状态分别显示。

## 找回批次、修正异常

展开“最近批次、逐行来源与异常续做”，打开相应回执，按行分类查找。

1. 选择“修正这一行”，修改原列值。
2. 预览此行修正；核对对象、字段组及原批次。
3. 提交后形成新批次和新声明，原始文件及原始行仍保留。成功行不需要重导。

对仍未编号的原设施，可通过明确的异常父行补充稳定编号；编号已占用或父行已被处理时会拒绝。需要把两个已有设施对应起来时，使用设施身份核对入口，不按名称或坐标自动合并。

字段来源冲突可以分别核对坐标、含水率、产量等字段组，说明选择理由；不是把两份资料的半组字段拼在一起。没有提交的修正只保留在当前页面，关闭或切换前留意提示；“找回批次”不等于自动保存尚未提交的输入。

## 查来源、标问题

设施档案显示本设施的来源行、列、模板与版本；历史未记录的内容明确显示缺失。整份台账原件仅地图管理员可下载，能看一口井不代表能取得整份台账。

有写入权限的员工可在现有档案中展开“标注资料问题”，选择正在核对的来源并说明问题。标注不会立即改写正式设施，也不会创建执行任务。提交失败时当前输入保留；未提交的说明不自动保存。

## 更新离线地图

继续使用受控地图包和既有发布机制。中断后按上传记录选择同一文件继续；不要把上传完成当作验包或发布成功。验包失败时查看失败原因，现用版本仍保留。公开地图只提供参考，不能覆盖内网已核验生产资料。

## 常见情况

| 页面状态 | 应怎样处理 |
| --- | --- |
| 没有匹配或空批次 | 核对当前来源、厂区与筛选，不据此断言全厂没有资料。 |
| 查询失败或权限受限 | 不能当作“没有问题”；重试或联系管理员核对权限。 |
| 预览过期 | 保留输入，读取最新资料后重新预览，不强行覆盖别人刚更新的值。 |
| 坐标系、单位或入口未知 | 留在待核范围，不改成确定坐标或可通行。 |
| 原件缺失、损坏或被撤销 | 使用状态提示联系管理员；页面摘要不代替可验证原件。 |

资料负责人首次配置的成本与后续更新的整理成本应分别记录。本指引没有预设真实节省分钟数或业务采用率。
