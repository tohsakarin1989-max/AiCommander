### 4.2 留存道路附件

现有`/api/case-results/{id}/document.docx`及`document.pdf`支持可选查询参数`road_artifact_id`。
不传时保持原冻结成果下载；传入时附加该条已保存的道路比较或路径，路径叠加到原成果的冻结地图。
服务不重新执行路由、不自动选择最新道路结果；原成果摘要保持不变，道路附件单独标识。
响应新增`X-Road-Artifact-ID`和`X-Road-Artifact-SHA256`，前端核对后才提供下载。
读取前及渲染结束后均重新核对案件、地图和道路权限；跨成果附件或失效引用不予交付。
底图或路径渲染失败时不交付省略地图的报告。客户端下载不修改原始案件或冻结成果。

本地无界面Office转换须使用可用中文字体及运维配置的`FONTCONFIG_FILE/PATH`。
仅检查PDF文件头不是排版验收：须检查中文可提取且页面无缺字，并目视核对地图及表格。
测试中的合成路径只验证导出管线，不证明路由业务正确性。
含地图版本或候选的输入暂以`frozen_map_renderer_required`拒绝，不能静默丢弃地图。
后续需要接通冻结地图图像、来源/复杂结构化数据的可读表格、长文分页和PDF。

后端已有`GET /api/case-results/{result_id}/document.docx`基础下载，登录和当前证据权限校验后
通过固定Node命令生成；标准输入传递正文，不接收路径或命令。每Web进程最多2个渲染、20秒超时，
输入上限8MiB，返回前检查输出格式及20MiB大小；这不是操作系统级内存隔离或跨进程全局配额。
不向子进程继承模型/数据库凭据、NODE_OPTIONS和代理配置，stderr不交付客户端。
结果在渲染后再次检查证据；返回no-store及服务器派生文件名。过大413、不可访问404、
渲染不可用/繁忙/超时503。含地图成果仍明确503，不返回省略地图的文件。
尚未在前端开放按钮；普通业务访问不依赖该渲染器。
